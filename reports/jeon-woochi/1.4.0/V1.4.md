# 도사 V1.4 — 액션과 모험, 전우치의 도술 보따리

기존 Godot 4.6.3/GDScript 프로젝트에서 작업했습니다. 새 프로젝트/저장소를 만들지 않았습니다. Android API29 이상 ARM64, 가로 화면, 기존 패키지 `com.suspiciousfactory.game`과 설치 서명을 유지하고 versionName 1.4.0/code10으로 올렸습니다. 변경 전 `bde22b4`를 `backup/dosa-v1.3` 브랜치로 보존했습니다. 광장 지형·NPC·타이틀 원본·기존 변신·그림 양방향 전환·첫 보상 기록은 유지했습니다.

## 휴대폰에서 테스트

기존 앱을 삭제하지 말고 업데이트 설치한 뒤 **이어하기**를 선택하세요. ‘게임 시작’은 기존처럼 새 진행을 저장합니다.

- 광장에서도 오른쪽 **점프**를 사용할 수 있습니다. 공격은 그림 임무 안에서만 가능합니다.
- 그림 장터 → 여우의 숲 → 그림 속으로. 공격을 연속으로 누르면 4연타로 연결됩니다. 가까운 전방 적을 조준 보정하며 공격 시 짧게 전진합니다. 점프 중 공격/부적술, 공중 공격 후 착지 타격, 회피 후 공격을 연결할 수 있습니다.
- 몬스터가 방망이를 들면 약 .42초 뒤 전방을 타격합니다. 이동·회피·점프로 피하세요. 실제 적중하면 HP와 체력바가 감소합니다. HP0에서는 임무 재시작 또는 광장 복귀를 선택합니다.
- 숲 입구 → 대나무숲 → 연못과 돌다리 → 오래된 사당 → 숲 깊은 곳으로 이동합니다. 지도는 메뉴 또는 미니맵 터치로 엽니다. 노란 점은 전투 목표의 고정 위치입니다. 마지막 전투 구역에는 여우 흔적과 귀환 표식을 배치했습니다.
- 대나무숲 보물상자, 물가 갈림길의 잎, 사당의 봉인물을 가까이서 **조사·획득**하면 실제 아이템이 지급됩니다. 이 탐험 보상은 저장되는 최초 수령 기록으로 재도전/재입장 중복 지급을 막습니다.
- 메뉴 → 가방은 **전우치의 도술 보따리**입니다. 5열×6행 30칸, 카테고리, 아이템 그림·수량·등급·선택 표시, 오른쪽 큰 그림과 이야기/효과/획득 장소/사용 버튼을 제공합니다. 아래 위로/아래로 버튼 또는 스크롤바로 아래 칸을 확인합니다. 아이템을 .55초 길게 누르거나 확대 감상을 누르면 큰 감상 화면이 열립니다. Android 뒤로가기로 감상 → 보따리 → 게임 순서로 닫습니다.
- 체력/도력이 가득 차면 물약을 소모하지 않습니다. 열쇠/부적/재료는 보관용이며 임의 사용·폐기 기능을 추가하지 않았습니다.

## 1. HP/공격 오류의 실제 원인

**숨겨진 광장의 물리 충돌체가 숲에도 남아 있었습니다.** V1.3 `load_forest()`는 `world.hide()`와 `set_process(false)`만 호출했습니다. 렌더링을 숨기고 Village의 `_process`를 멈춰도 자식 StaticBody2D는 물리 공간에 남습니다. 숲의 AStar 데이터에는 없는 광장 건물이 이동·공격 경로를 막을 수 있었습니다.

새 검사에서 광장 물리를 예전처럼 켜면 숲의 `(600,650) → (670,685)` 공격선이 차단되고, 광장 process mode를 disabled로 바꾸면 같은 선이 열리는 것을 실제 물리 ray로 재현했습니다. 임무 중에는 광장 트리를 `PROCESS_MODE_DISABLED`로 전환해 CollisionObject의 기본 disable-mode에 따라 물리 공간에서도 제거합니다. 플레이어는 별도 숲 트리에 있으며, 광장 복귀 시 원래 process mode를 복원합니다. 원래 위치·방향과 NPC 진행은 보존합니다.

또한 V1.3 피해 수신은 `can_fight()`를 공유해 **플레이어가 변신 중이면 피해도 무시**했습니다. `can_take_damage()`를 분리해 공격 가능 여부와 관계없이 임무 중 유효한 피격을 처리합니다. 몬스터의 27단위 공격 시작/37단위 타격과 길찾기의 42단위 직진 제한도 조작감에 불리했습니다. 공격 시작43/타격52, 경로 끝점의 가까운 유효 셀 탐색, 막혔을 때 시야 확인 후 접근으로 변경했습니다.

피해 수신은 HP 감소 → 체력바 즉시 갱신 → 붉은 피격/경직/충돌 넉백/소리 → 저장을 연결합니다. 무적 .5초, 경직 .13초는 설정값입니다. HP0에서 이동·공격을 중단하고 몸이 기울어지는 전투 불능 자세와 재도전 화면을 표시합니다. 재도전은 체력/도력을 최대로 회복하고 몬스터/진행을 초기화하며, 기존 영구 보상·아이템·레벨·탐험 수령 기록은 지우지 않습니다.

## 2. 콤보·점프·도술

- `action_config.gd`에 조준 거리220, 전방 보정 반각80도, 공격 반각65도, 거리/피해/시간/무적/스킬 소모를 분리했습니다. 발밑 월드 좌표와 정적 장애물 시야 검사를 사용합니다. 조준은 공격 시작 시 결정하며 사망한 적을 따라 계속 회전하지 않습니다.
- 기본 공격은 넓은 전방 부채꼴입니다. 1타20, 2타22, 3타13+13, 4타34 피해로 100/110/130/170%를 구현합니다. 3타의 두 타격은 의도된 별도 펄스이며 공격별 피격 ID를 기록해 중복 피해를 막습니다.
- 다음 입력 세 개까지 예약합니다. 전투 버튼은 일반 화면 전환 버튼의 한 프레임 중복 방지 대신 액션 컨트롤러로 직접 전달해 빠른 연타를 버리지 않습니다. .95초 입력 간격/빗나감으로 연결을 초기화하며 실제 적중으로 HIT 카운터를 갱신합니다.
- 새 액션 시트의 장풍/부적 휘두르기/양손 연타/승천/점프/공중 장풍/착지/피격 자세와 서로 다른 부채꼴·연타·상승 이펙트를 사용합니다. 기존 8방향 걷기 시트는 그대로입니다. 새 공격 자세는 앞쪽 시점과 좌우 반전이며 모든 방향의 전용 공격 시트를 새로 그린 것은 아닙니다.
- 전진은 실제 CharacterBody 이동에 더하고 벽/몬스터 충돌을 유지합니다. 점프의 높이·수직 속도와 그림자/충돌 발밑 좌표는 독립적입니다. 점프로 벽을 통과하지 않습니다. 공중 공격 후 착지 타격을 연결하며 4타는 몬스터를 짧게 띄웁니다.
- 기본 공격 → 부적술, 점프 → 공중 부적술, 봉인 → 연타를 같은 입력 예약 상태로 처리합니다. 둔갑은 공격 중 겹치지 않도록 제한하고 기존 변신을 보존했습니다. 회피는 액션을 취소하고 다음 공격으로 연결합니다. 분신/축지와 새 의상은 기존처럼 잠금입니다.
- 몬스터는 준비/실제 공격/빈틈을 구분하고, 준비 시 방향을 고정한 뒤 실제 타격 프레임에 거리·각도·장애물·플레이어 점프/회피를 검사합니다. 일반 피격 경직에는 .9초의 재경직 간격을 두어 매 타격마다 공격 준비가 무한 취소되지 않도록 했습니다.
- 기존 네 효과와 개별 설정을 유지합니다. 일반 히트 스톱 .08초, 4타 .11초, 흰색 강조 .1초, 일반 흔들림45%/강공격100%, 파랑·금색 파편/숫자와 별도 사망 소멸을 연결했습니다. 전역 시간을 멈추지 않으며 UI는 흔들리지 않습니다.

## 3. 확장된 숲

월드 캔버스 1500×1080 → 3000×2160. 내부 이동 사각형은 1280×740 → 2780×1820이며, 물·바위·대나무·사당 충돌을 제외한 20단위 표본 이동 면적은 약 **5.79배**입니다. 카메라 확대율2와 캐릭터 크기를 유지했습니다. 검사에 사용한 이전 영역도 보수적으로 같은 현재 충돌 데이터에서 측정했습니다.

| 구역 | 중심 좌표 | 콘텐츠 |
|---|---|---|
| 안개 낀 숲 입구 | 400,750 | 기존 진입/복귀, 나무 바닥, 안내 |
| 대나무숲 | 1000,700 | 첫 도깨비, 보물상자 갈림길 |
| 연못과 돌다리 | 1700,1110 | 실제 건널 수 있는 돌다리, 물/반사·연꽃·안개, 숨겨진 잎 |
| 오래된 사당 | 2450,650 | 기존 HD 사당 오브젝트, HP120 도깨비, 봉인 부적 |
| 숲 깊은 곳 | 2680,1720 | HP100 도깨비, 빛나는 여우 흔적/발자국/완료 위치 |

첫 도깨비 HP60, 사당120, 마지막100입니다. 기존 처치 ID0~2와 첫 임무 보상은 유지해 V1.3의 완료/수령/진행을 호환합니다. 바닥은 독립 지형 데이터에서 Godot로 베이크하며 대나무·나무·사당·석등·상자·물 경계와 실제 충돌을 분리했습니다. 넓힌 지역에도 길/갈림길/가장자리 식생을 배치하고 전체 바닥·배경/카메라 경계를 맞췄습니다. 유료 API 없이 자체 생성한 약한 바람 소리, 기존 국악 BGM을 사용합니다.

## 4. 보따리와 저장

- 전용 남색/먹색 전면 화면, 금빛 전통 테두리와 기존 문양 UI. 왼쪽 보관함 약60%, 오른쪽 감상 약40%. 30개 실제 슬롯과 빈 슬롯, 수량, 회색/파랑/보라/금색 등급, NEW/선택 표시. 여섯 카테고리와 오른쪽 큰 아이템 그림/설명/효과/수량/출처/사용을 연결합니다.
- 새 3×2 아틀라스에서 붉은 약병, 푸른 도력 약병, 봉인 한지 부적, 빛나는 잎, 청동·옥 열쇠와 보물상자를 각각 사용합니다. 기존 한 글자 아이콘은 새 가방에 사용하지 않습니다.
- 빠른 등장 확대, 약병 액체 반사선/입자, 떠 있는 부적, 반짝이는 잎, 열쇠의 느린 각도 변화. 길게 누르기/확대 버튼에서 실제 큰 그림과 이야기를 봅니다. 감상 중에는 뒤쪽 보따리 버튼도 비활성화합니다.
- 실제 물약 사용은 기존 모델과 원자적 저장을 그대로 사용합니다. 획득은 아이콘/이름/빛 파편/수량 갱신과 첫 발견 표시로 연결합니다. 카테고리는 표시만 필터링하며 아이템을 변경하지 않습니다.
- RPG 저장 version1 → 2. 기존 HP/MP/경험치/레벨/수량/슬롯/보상/임무/광장 복귀를 보존하고 `rarities`, `loot_claims`, `discoveries`, `seen_items`, `visited`에 기본값을 추가합니다. JSON 숫자형을 정규화합니다. 없는 아이템/음수 수량/중복 도술/잘못된 버전을 계속 거부합니다.
- 캐릭터/도술 메뉴도 같은 남색 패널과 금빛 테두리/아이콘 스타일을 사용합니다. 등급 승급이나 새 도술/의상 콘텐츠는 추가하지 않았습니다.

## 6. 한계와 미구현

실제 플레이 가능한 첫 액션/탐험 임무 업데이트입니다. 추가 그림 임무, 분신술/축지법, 새 의상, 등급 승급 과제, 상점 구매는 여전히 미구현/잠금입니다. 숲의 바닥·바위·물·여우 흔적 일부는 절차적 임시 아트이며 고급 HD-2D 환경 전체를 새로 제작한 것은 아닙니다. 전용 실크/목재 질감 아틀라스 대신 현재 남색 패널과 금빛 전통 문양을 사용합니다. 액션은 새 여덟 자세와 효과를 조합하며 모든 방향의 다중 프레임 공격 시트는 아닙니다.

실제 갤럭시나 Android 에뮬레이터를 실행할 수 없는 환경입니다. Linux Godot의 실제 물리/네이티브 ScreenTouch 입력/렌더링과 APK 리소스 검사는 실기기 검증으로 표시하지 않습니다. 최종 휴대폰 스피커·안전 영역·발열/60FPS 확인은 별도입니다. 기존 공개 저장소의 표준 Ubuntu Actions를 사용하고 별도 서버나 유료 API를 만들지 않았습니다.

## 7. 최종 검증과 APK
