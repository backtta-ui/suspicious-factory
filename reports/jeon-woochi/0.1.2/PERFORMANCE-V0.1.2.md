# V0.1.2 끊김 완화 및 효과음

## 확인한 부하와 수정

- V0.1.1 돌길은 작은 돌마다 polygon/line을 호출해 그렸습니다. 정적인 그리기 명령은 Godot가 보존해도 매 프레임 GPU 제출 비용은 남았습니다. 동일 돌길을 개발 시점에 `tools/bake_ground.gd`로 한 번 렌더링해 `assets/woo/ground_baked.png`에 저장하고 런타임에는 Sprite2D 하나로 표시합니다. 원본 절차적 지형 코드와 실제 벽·건물 충돌은 유지합니다.
- 등불 5개의 PointLight2D를 가벼운 가산 혼합 Sprite2D로 바꿨습니다. 밝기와 낮·밤 변화는 유지하고 실시간 주변 표면 조명 패스는 제거했습니다.
- 전체 화면에 원경 이미지를 다시 그리던 반투명 안개를 제거하고 꽃잎을 36→18개, 30Hz로 줄였습니다. 먼 배경과 벚나무·등불 아트는 유지합니다.
- 화면은 1280×720 기준 viewport로 렌더링해 고해상도 폰의 픽셀 처리량을 제한하며 60FPS 상한을 둡니다. 기존 네이티브 터치 좌표 변환은 유지하고 여러 화면 크기에서 재검사합니다.
- 자동 저장은 별도 스레드로 수행합니다. 수동 저장·백그라운드 전환·종료는 진행 중인 저장을 합류시킨 후 처리해 파일 쓰기를 직렬화합니다. JSON 임시 파일·백업·복구 방식과 기존 저장 호환성을 유지합니다.
- 기존 터치 진단은 숨겨진 상태에서도 매 이벤트 파일을 열어 기록했습니다. 이제 기본 세션에서는 진단과 파일 쓰기를 끕니다. 개발 환경에서 `WOO_TOUCH_LOG=1` 또는 `WOO_TOUCH_OVERLAY=1`로 다시 켤 수 있습니다.

## 효과음

직접 합성한 로컬 PCM WAV 5종을 포함합니다: 버튼, 발걸음, 항아리 이동, 성공한 둔갑, 대화. 실제 이동 거리 기준으로 발소리를 내며 벽에 막힘·정지·순간 위치 변경은 소리를 만들지 않습니다. 재사용 대기 중 도술은 소리를 중복 재생하지 않습니다. 미리 로드한 클립과 최대 6개 음성 풀을 사용하며 입력 순간 파일 읽기나 합성을 하지 않습니다.

설정의 ‘효과음: 켜짐/꺼짐’은 즉시 적용·저장됩니다. 외부 음원·서버·권한은 추가하지 않습니다. 오디오 장치가 없는 CI의 Dummy 드라이버는 WAV 재생을 건너뛰고 요청 경로와 자원·음소거를 검사합니다. 이 검사는 실제 스피커 청취 테스트가 아닙니다.

## 검증 범위

- 게임 53, 네이티브 터치 125, 저장 복구 11, 소리·성능 구조 및 비동기 저장 20개 검사와 별도 프로세스 write/read/exit 검사.
- APK 검사 23개: 기존 패키지 `com.suspiciousfactory.game`, 동일 서명, versionName 0.1.2 / versionCode 6, Android 10+, ARM64, 오프라인 권한 없음, 음원·사전 렌더링 지형 포함.
- 실제 APK 리소스를 데스크톱 Godot에서 렌더링해 메뉴·이동·두 손가락 둔갑·항아리·대화 검사를 반복합니다.
- 성능 비교는 같은 1280×720 장면의 60프레임 워밍업 후 180프레임을 측정합니다. 원본 V0.1.1 APK와 V0.1.2 APK에 같은 `tests/render_benchmark.gd`를 실행합니다. llvmpipe 소프트웨어 렌더러 결과이므로 갤럭시 FPS로 해석하면 안 됩니다.

갤럭시 실기기 FPS·발열·스피커 소리 확인은 아직 수행하지 않았습니다. 사용자가 알려준 끊김을 재현하는 실기기에 접근할 수 없으므로, 확인한 렌더링·입출력 부하를 줄이고 APK를 다시 제공하는 범위입니다.
