# 도사 V2.0 구현 보고

기존 Godot4.6.3/GDScript 프로젝트를 확장했습니다. 변경 전 `backup/dosa-v1.4`에 c8cc87d를 보존했습니다. 패키지 `com.suspiciousfactory.game`, 기존 서명키, Android10+/ARM64/가로 화면과 기존 저장 구조를 유지합니다. 표시 버전2.0.0/코드11입니다.

## 실제 구현

캐릭터 오류 원인은 별도 공격 시트를 작은 배율로 교체하던 코드였습니다. 모든 인간 상태에 기존 `hero.png`의 동일한 방향별 기준 프레임·발 피벗·배율을 사용합니다. 원본 부위를 나누어 팔·다리를 움직이고 머리는 동일 픽셀로 마지막에 그립니다. 점프 준비·상승·최고점·하강·착지와 지면 그림자를 분리했습니다.

장타·부적·봉·푸른 파동의 서로 다른4자세/궤적, 입력 예약, 발밑 좌표 판정·방향 보정·충돌·중복 피해 방지를 구현했습니다. 공중 부적은 실제 낙하체가 지면에서 폭발해 피해를 줍니다. 기존 HP·전투 불능·재도전·네 타격 효과를 유지하고 전용16아이콘과 원형 쿨타임을 추가했습니다. 원화 전체를 새로 그린 프레임 애니메이션은 아니며 기존 픽셀 부위의 관절 애니메이션입니다.

기존 여우의 숲5구역·보물·30칸 아이템 가방·성장·광장 복귀를 보존하고 사당에3단계 문양 퍼즐, 귀중품을 보호하는 아이템 버리기와 저장을 추가했습니다. 기존 완료 저장도 고양이 외형을 해금합니다. 이미 확장된V1.4 맵을 이번에 다시4~6배 확장했다고 주장하지 않습니다.

봉인의 밤은 headless Godot 전용 서버가 방·역할·이동/충돌·거리·쿨타임·미션·포획/구출·투표·승패를 판정합니다. 개인별 스냅샷에 본인 역할, 요괴인 경우 동료만 전달하고 시야 밖 좌표를 숨깁니다. 정상 외형과 이름표는 역할별로 다르지 않습니다.

빠른 대전·6자리 방·준비·방장 시작·6~8인/요괴2명·30초 준비·8분 경기·재대전·40초 재접속·방장 이전이 연결되어 있습니다. 기둥 문양·우물 회전·혼불 운반·부적 복원은 서버 미션 자원을 갱신하며 요괴 가짜 수행은 자원을 늘리지 않습니다. 자원 소모 회의·투표/기권/동점·오봉인 제한·추가 자원 경로·요괴2명 봉인 승리를 구현했습니다.

감옥·구출 채널·보호·마지막 탈출 기회를 고려한 전원 포획 판정, 공통8도술과 요괴5능력은 서버 상태를 사용합니다. 외형 복제와 실제ID는 분리합니다. 싱글플레이 콤보는 멀티에 적용하지 않습니다. 신규 사용자도8도술을 선택하며 모험 연동은 현재 고양이 외형입니다. 서버 계정 없는 오프라인 세이브를 경쟁 우위의 인증으로 신뢰하지 않는 설계입니다.

## 검증과 미완료

전체 checkpoint에서 기존 회귀·터치·저장/프로세스 재시작과 V2 캐릭터23개·서버 규칙51개·실제 소켓27개·연결된 게임 UI13개 검사가 통과했습니다. 8인 방과 별도6인 방은 자동화 클라이언트의 실제 TCP/WebSocket 접속입니다. Linux 그래픽으로 대기실·준비·이동·자세를 렌더링했습니다. 사람6~8명/갤럭시 실기기 검증은 아닙니다.

APK 검사 항목은 ARM64·API29/36·Internet 단일 권한·가로 화면·16KiB 정렬·기존 서명·버전·게임 리소스입니다. 기존 Actions와 `tools/checkpoint.sh`를 유지합니다. 최종 공개 다운로드/Actions 증거는 배포 결과에 별도 기록합니다.

공개 Render 서버는 미배포입니다. Docker 구성은 제공하지만 Render 실환경 CPU/TLS/절전/장시간 부하·Android 실기기60FPS는 미검증입니다. 기존 마을 아트를 재사용한 멀티 맵이며 완전히 새로운 전용 미술 맵은 아닙니다. 영구 계정·기기변경 복구·구매 검증·공개 운영용 신고/차단은 완성되지 않았습니다. 유료 전환은 없습니다.

서버 없이 APK 모험을 사용할 수 있습니다. 휴대폰 무료 배포는 [V2.0-SERVER.md](V2.0-SERVER.md)를 따르세요.
