# 봉인의 밤: 휴대폰으로 무료 서버 열기

공개 서버는 아직 미배포입니다. 최신 멀티 사용법은 [2.0.2 안내](MULTIPLAYER-2.0.2.md)를 함께 확인하세요. 서버 주소 없이도 기존 싱글플레이·저장·이어하기와 APK 빌드를 사용할 수 있습니다.

## 삼성 인터넷 또는 Chrome

1. https://dashboard.render.com 에서 GitHub로 무료 계정을 만듭니다. **카드·결제수단은 등록하지 마세요.** Hobby 작업 공간을 선택합니다.
2. **New → Blueprint**에서 기존 `backtta-ui/suspicious-factory` 저장소, `main`, `render.yaml`을 연결합니다. 저장소가 안 보이면 Render GitHub 앱에 이 저장소만 허용합니다.
3. 생성할 서비스가 **Docker / Free / Singapore**인지 확인합니다. 유료 요금이 표시되거나 Free 선택이 불가능하면 중단합니다. 새 저장소는 필요 없습니다.
4. 배포 후 Logs와 Live 상태를 확인합니다. 첫 Docker 빌드는 몇 분 걸립니다. Blueprint 대신 **New → Web Service**를 쓰면 같은 저장소, Dockerfile `server/Dockerfile`, Free, Singapore, Health check `/health`, 환경변수 `PORT=10000`, `MAX_ROOMS=1`, 자동 배포 끄기를 지정합니다.
5. 발급된 `https://서비스이름.onrender.com/health`를 브라우저로 열어 JSON 정상 응답을 확인합니다. 절전 해제에는 약 1분 걸릴 수 있습니다.
6. APK → **봉인의 밤 · 멀티플레이** → 서버 주소에 발급된 HTTPS 주소를 입력합니다. 앱이 WSS로 변환합니다. 참가자 모두 같은 주소를 사용합니다.
7. 한 명이 방 만들기 → 6자리 코드 공유 → 나머지 입장 → 모두 준비 → 방장 시작. 최소 6명, 최대 8명입니다. 연결 실패 시 Live 상태·`/health`·주소 오타를 확인합니다. 서버 업데이트는 Render Manual Deploy로 명시적으로 실행합니다.

## 무료 한도

유료 플랜·유료 API·결제 SDK·자동 결제 전환은 구현하지 않았습니다. Render 계정도 **카드 미등록**을 기본으로 합니다. 이미 카드가 있다면 포함량 초과 과금과 지출 한도를 확인하고, 비용을 0원으로 제한할 수 없으면 진행하지 마세요.

공식 안내(2026-11 조사): 무료 512MB/0.1 CPU, 작업 공간당 월 750시간, 15분 HTTP/WebSocket 메시지가 없으면 절전, 재기동 약 1분. 실제 WebSocket 메시지가 오가는 경기는 절전 대상이 아닙니다. Hobby 포함 외부 전송량은 월 5GB로 안내됩니다. 카드가 없으면 초과 시 서비스가 중지될 수 있습니다. 빌드 분은 공식 문서별 500/1,000분 표기가 달라 **계정 대시보드의 현재 한도**를 확인하세요. 무제한 무료가 아닙니다.

2.0.2 로컬 측정에서는 gzip 적용 후 평균 스냅샷 약1.9KB × 초당10회 × 8명 × 8분이 약72MB이며 TLS·대기실·수련 등의 통신이 추가됩니다. 5GB는 수십 판 수준일 수 있습니다. 무료 기본 구성은 **동시 한 방, 최대8명**입니다. 서버 20Hz 판정/10Hz 전송과 클라이언트 보간을 사용하며 무료 CPU의 지연·60FPS를 보장하지 않습니다.

연결이 끊긴 자리는 40초 보존하고 자동 재접속을 시도합니다. 방장은 접속자에게 이전됩니다. 서버 재시작·새 배포·절전 후 재기동 시 메모리의 방은 사라집니다. 새 방을 만드세요. 긴 콜드 스타트에서 이전 경기 복구는 보장하지 않습니다. 싱글플레이 저장은 기기에 남습니다.

## 검증 범위와 식별

실제 Render 배포·무료 인스턴스 부하·서로 다른 갤럭시6~8대의 인터넷 플레이는 미검증입니다. 실제 소켓 자동화 테스트와 사람의 실기기 테스트를 구분합니다.

익명 ID·재접속 비밀값은 앱 전용 파일에 저장합니다. 앱 데이터 삭제·기기 변경 시 자동 복구되지 않습니다. 구매·계정 복구 기능은 없습니다. 2.0.2부터는 그림 수련에서 서버가 습득을 확인한 도술만 장착합니다. 무료는 역할별 보유 후보 중2개를 준비 단계에 추첨하고, 요괴에게 사물 둔갑을 배정하지 않습니다. 기존 오프라인 해금 기록은 보존하지만 서버 권한으로 자동 인증하지 않습니다.

개발용: `godot --headless --path . --script res://scripts/seal/server.gd -- --port=10000`. LAN은 `ws://사설IP:10000`, 공개 인터넷은 인증서 검증이 있는 WSS만 허용합니다. 앱에 공개 주소·서버 비밀키를 하드코딩하지 않습니다.

검사: `python3 tools/test_seal_network.py`, `python3 tools/test_seal_network.py --ui-only`, 전체 빌드 `bash tools/checkpoint.sh`.

공식 정책: https://render.com/docs/free · https://render.com/pricing · https://render.com/docs/outbound-bandwidth · https://render.com/docs/build-pipeline · https://render.com/changelog/free-web-services-now-remain-active-while-receiving-websocket-messages

## 2.0.2 서버 업데이트와 진행 복원

기존 서버도 최신 main을 Manual Deploy해야 프로토콜3 APK가 연결됩니다. Blueprint는 `SEAL_PROGRESS_KEY`를 서버에서 자동 생성하도록 설정되어 있습니다. 이 키는 앱이나 채팅에 입력하지 않고 Render 환경변수에 유지하세요. 서명된 습득/승수 체크포인트가 앱에 저장되므로 서버 파일이 사라져도 같은 키를 유지하면 검증 복원이 가능합니다. 키까지 바뀌면 과거 체크포인트는 검증되지 않습니다. 기존 로컬 기록은 삭제하지 않습니다.

운영 기본은 항상 무료입니다. `SEAL_TEST_ENTITLEMENTS=1`은 개발자가 서버 기록을 직접 준비해 유료/VIP 규칙을 검사하는 테스트 전용이며 실제 결제 또는 구매 검증 기능이 아닙니다. 새 서버를 처음 배포할 때는 기존 Blueprint의 Free·카드 미등록 조건을 유지하고 해당 테스트 플래그를 켜지 마세요.
