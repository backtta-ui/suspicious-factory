# 도사: 전우치 V0.1 전환·검증 보고서

## 1단계: 실제 분석·빌드·백업

실제 프로젝트는 `scenes/main.tscn`으로 시작해 GDScript가 CanvasLayer UI와 Node2D 월드를 만드는 Godot 4.6.3 stable 프로젝트였습니다. 공장 V0.2 미커밋 변경도 버리지 않고 `backup/suspicious-factory` 브랜치 **384c857**에 보존해 같은 GitHub 저장소에 push했습니다.

그 상태에서 checkpoint의 게임·터치 검사와 APK 빌드·서명·Manifest 검증이 통과했습니다. 기존 APK는 `/workspace/suspicious-factory/builds/suspicious-factory-0.2.0.apk`, SHA256 `e4d8bc44e0bee8b25818f134a71f1c56974766d91b53eb5e2e35b206bbfe7ca9`였습니다. 미완성 멀티플레이를 완성했다고 보고하지 않았습니다.

| 재사용 | 백업 후 main에서 제거·교체 |
|---|---|
| 엔진·한글 폰트·Android preset·템플릿 | 공장 맵·직원 캐릭터·제조 설비 |
| 터치 조이스틱·입력 진단 | 공장 미니맵·설비 안내·꾸미기 |
| 패키지·서명키·증가하는 versionCode | 개발용 이동 서버·네트워크 연결 |
| Cloud 빌드·APK 검증·기존 GitHub 배포 | 공장 전용 테스트·문서 |

Godot의 등각 투영·Y 정렬·2D 조명으로 이번 목표가 가능해 엔진을 바꾸지 않았습니다. 원본 픽셀 리소스와 2D 깊이 표현을 사용하며 최종 상용 HD-2D·3D 심도 그래픽이라고 주장하지 않습니다.

## 2단계: 메뉴·캐릭터 이동

`main.gd`와 `scripts/woo/actor.gd`, `mobile_button.gd`, 새 픽셀 시트를 구현했습니다. 메뉴 4개, 검은 갓·도포, 대기/눈깜박임, 8방향 걷기·달리기, 이동 충돌을 제공합니다. 버튼은 원본 터치를 소유해 변환된 마우스와 중복 실행하지 않고, 서로 다른 손가락으로 조이스틱과 달리기·도술을 동시에 사용할 수 있습니다.

## 3단계: 마을·카메라

`village_layout.gd`, `village.gd`, `village_prop.gd`에 한옥 4채, 돌길, 나무 12그루, 우물, 장터, 등불 5개와 경계를 구현했습니다. 다각형·원형·선분 충돌은 그림과 분리합니다. 카메라 2배 확대와 부드러운 추적, 1800×960 경계 제한, Y 깊이 정렬을 사용합니다. 소형 공유 텍스처·그림자 없는 조명·정적 지형과 투영 그림자로 비용을 제한했습니다. 실기기 FPS는 측정하지 않았습니다.

## 4단계: 도술·NPC·저장

항아리 둔갑/인간 복귀, 0.42초 입자 변신, 느린 항아리 이동, 2.5초 쿨타임을 제공합니다. 주민 3명은 근처를 작게 이동하거나 대기하고, 가까이 가면 대화할 수 있습니다. 우물 조사도 가능합니다.

8초 자동 저장과 앱 이탈·메뉴 복귀·종료 저장을 구현했습니다. 위치·맵·설정·도술 해금·변신·시간을 저장하고, 임시 파일 원자적 교체와 이전 정상 파일 백업을 사용합니다. 주 파일 손상 시 백업을 읽고 손상 데이터를 거부합니다. 계정과 외부 서버는 사용하지 않습니다.

## 5단계: 검증·APK

게임 검사 47개, 터치 검사 115개, 저장 복구 검사 9개, 별도 엔진 프로세스의 write/read/exit 경로를 빌드 전에 실행합니다. 실제 Input.parse_input_event → Window 좌표 변환 → 버튼·조이스틱 → 화면 전환을 검사합니다.

1280×720, 2400×1080, 2340×1080, 2280×1080, 960×540의 버튼 영역·피드백·두 손가락 입력·도술·대화·설정·메뉴·이어하기를 검증합니다. Linux OpenGL의 실제 화면도 렌더링·캡처합니다. APK의 서명·패키지·최소 OS·오프라인 권한·리소스·정렬을 별도로 검사합니다.

패키지 ID `com.suspiciousfactory.game`과 기존 서명키를 유지하고 표시 이름은 도사: 전우치, versionName=0.1.0, versionCode=4로 설정했습니다. 이전 공장 설치 위에 업데이트할 수 있습니다. 이전 APK는 보존하며 새 파일은 `jeon-woochi-0.1.0.apk`입니다.

**새 게임을 실제 갤럭시나 Android 에뮬레이터에서 실행하지 않았습니다.** Linux 렌더링과 입력 시뮬레이션은 Android OS 실행을 대신하지 않습니다. APK에 포함된 리소스와 새 입력 경로를 검사하지만, 제조사 화면·발열·시스템 내비게이션은 휴대폰 확인이 필요합니다. 원격 Actions 성공도 주장하지 않습니다.

최신 결과와 SHA256은 배포 브랜치의 버전별 보고서를 기준으로 합니다.

## 휴대폰 확인 순서

1. 업데이트 설치하고 앱 이름 ‘도사: 전우치’를 확인합니다.
2. 게임 시작 → 조이스틱 사방 이동 → 다른 손가락으로 달리기를 누릅니다.
3. 한옥·우물·마을 경계를 향해 밀어 충돌을 확인합니다.
4. 도술로 항아리 변신 → 이동 → 쿨타임 뒤 인간 복귀를 확인합니다.
5. 주민 근처에서 대화 → 다음 → 닫기. 메뉴·뒤로가기를 확인합니다.
6. 저장하고 메인으로 → 종료 → 재실행 → 이어하기로 위치 복원을 확인합니다.
7. 홈 화면으로 나갔다 복귀하면 메뉴가 열리고 이동이 멈춰 있어야 합니다.
