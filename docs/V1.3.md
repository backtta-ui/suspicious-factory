# 도사 V1.3 — 그림 속 여우의 숲

기존 저장소 / Godot 4.6.3 / GDScript / Android 10+ ARM64 / 가로 화면을 유지합니다. 패키지 `com.suspiciousfactory.game`, 기존 설치 서명을 유지하고 versionName 1.3.0, versionCode 9로 올렸습니다. 변경 전 main `783d44c`를 `backup/dosa-v1.2` 브랜치로 보존했습니다. V1.2 광장의 레이아웃·지형·캐릭터·NPC 아트·타이틀 원본은 교체하지 않았습니다.

## 휴대폰 플레이

1. 기존 앱을 삭제하지 말고 최신 APK를 업데이트 설치합니다. 기존 진행을 유지하려면 **이어하기**를 누르세요. ‘게임 시작’은 기존과 같이 새 게임을 시작합니다.
2. 광장의 **신비로운 그림 장터**로 이동해 첫 번째 **여우의 숲** 그림에 접근하고 ‘그림 보기’를 누릅니다.
3. 커다란 그림 화면에서 목표·첫 보상을 확인하고 **그림 속으로**를 누릅니다. 약 2.35초간 테두리·부적·입자·먹물 소용돌이·확대와 화면 전환이 진행됩니다.
4. 오른쪽 큰 **공격**은 마지막 바라본 방향으로 푸른 도술을 발사합니다. **슬롯 1 부적술**은 도력 12를 쓰고 적을 잠시 봉인합니다. **슬롯 2 둔갑술**은 기존 항아리 변신/복귀입니다. 변신 상태에서는 공격할 수 없습니다. **회피**는 이동 방향 또는 바라본 방향으로 짧게 이동하며 장애물을 통과하지 않습니다.
5. 꼬마 도깨비 3마리를 처치하면 첫 완료 경험치 120, 엽전 50, 회복약 2개, 신비한 잎 3개가 지급됩니다. **광장으로 돌아가기**를 누르면 그림 진입 직전 위치·방향으로 돌아옵니다. 출구로 조기 귀환할 수도 있으며, 조기 귀환 후 새로 입장하면 미완료 임무가 다시 시작됩니다.
6. 메뉴에서 가방·캐릭터·도술·임무 일지·지도·의상·설정을 엽니다. 체력/도력이 부족할 때 해당 물약을 사용하세요. 지도 또는 Android 뒤로가기로 창을 닫습니다. 전투 효과 네 가지는 설정 → 전투 효과 설정에서 개별 조절합니다.

## 실제 구현

### 1. RPG와 저장

- 30슬롯 가방과 아이템 중첩, 다섯 초기 아이템, 설명·수량·사용 가능 상태, 회복약/도력 회복약의 실제 효과·소비·저장. 부적/재료/열쇠는 보관용이며 사용 버튼을 비활성화합니다. 아이콘은 현재 글자 문양입니다.
- 경험치·레벨·레벨업 최대 HP/도력 증가·현재 HP/도력·엽전, 실제 도술 2개와 3슬롯 장착, 첫걸음 퀘스트를 포함한 일지와 그림 완료 상태, 미니맵·전체 지도.
- 도사 등급 다섯 이름과 향후 수련 연동 구조를 준비했습니다. 자동 승급 콘텐츠는 추가하지 않았습니다. 분신술·축지법은 잠금입니다. 새 의상 에셋이 없으므로 기본 갓·도포만 표시합니다.
- 기존 최상위 schema-1 파일/백업/원자적 교체와 광장 좌표를 유지하고 `rpg.version=1`을 추가합니다. 옛 저장에 필드가 없으면 기본값을 적용합니다. 임무의 현재 좌표·방향·처치 ID·완료 상태는 `rpg.session`, 광장 복귀 좌표/방향은 기존 `return_anchor`에 보관합니다.
- JSON 숫자를 읽을 때 몬스터 ID와 수량·스탯을 정수로 정규화합니다. 정수 ID와 JSON 소수형 ID의 `Array.has` 차이로 몬스터가 재등장할 수 있던 개발 중 문제를 수정했습니다. 알 수 없는 아이템·음수 수량·중복 도술·잘못된 임무 데이터를 거부합니다.
- 보상 지급과 수령 기록을 한 저장 스냅샷으로 기록하고 저장 성공 후 완료 창을 표시합니다. 저장 실패 시 상태를 롤백합니다. 이번 첫 임무 보상은 **그림별 최초 1회**입니다. 재입장/재실행으로 중복 지급하지 않습니다.

### 2. 조작과 발소리

- 기존 조이스틱 174×174 디자인을 유지하고 논리 좌표 기준 오른쪽 30 / 위 12만큼 옮겼습니다. Android 표시 안전 영역을 환산해 추가 여백을 적용합니다. 손가락을 잡은 뒤 영역 밖으로 드래그해도 소유권을 유지합니다.
- 발밑 좌표를 실제 돌광장·길·풀·흙·숲의 나무 데크·숲 연못의 얕은 물 데이터와 대조합니다. 이동 거리 기준 주기로 재생해 달리면 자연스럽게 빨라지고 정지/벽/순간 이동 때 소리가 나지 않습니다. 좌우 발의 피치를 다르게 하며 가까운 NPC도 거리 기준 발소리를 냅니다.
- CC0 Kenney 샘플의 발췌·필터 편집과 자체 제작 물소리를 사용합니다. 기존 국악 BGM과 음원 크레딧을 보존합니다. 유료 API/서비스는 사용하지 않습니다.

### 3. 그림과 임무

- 여우의 숲 전용 HD 도트 그림, 큰 감상 화면, 제목·소개·목표·보상·입장/뒤로. 원본 그림은 고정하고 안개·대나무 선 레이어·여우 눈빛·반사광·주변 입자를 국소적으로 움직입니다.
- 탐관오리의 관아와 도깨비의 밤은 기존 그림과 소개를 유지하고 준비 중으로 잠급니다.
- 전환 중 모든 터치 버튼/이동을 차단하고 중복 입장을 막습니다. 전환 양방향, 임무 로드 후 조작 복구, 잘못된 진입 상태의 광장 복귀 처리를 연결했습니다.
- 여우의 숲은 1500×1080 월드 범위의 별도 실제 이동 맵입니다. 바닥은 Godot에서 생성한 돌길/흙/풀/나무/물 지형을 미리 베이크하고, 대나무·나무·석등·바위·물 경계는 별도 오브젝트/충돌로 구성합니다. 미니맵에는 자기 위치와 고정 임무 지점/출구만 표시합니다.

### 4. 전투와 AI

- 광장에서는 전투 버튼을 숨길 뿐 아니라 게임 코드에서도 공격을 거부합니다. 비전투 둔갑술은 유지합니다.
- 실제 이동 투사체의 물리 ray 검사를 통해 기본 공격 20 피해, 부적술 32 피해/도력 12/봉인 1.4초를 적용합니다. 공격 간격 .32초, 부적 2.2초, 회피 1.6초 쿨타임입니다.
- 꼬마 도깨비 3마리: HP 60, 대기/순찰/발견·추적/공격 예고/근접 12 피해/공격 후 쉬기/피격/봉인/죽음. 재사용 AStarGrid 경로를 .65초 이상 간격으로 요청하고, 막히면 대기합니다. 매 프레임 경로를 계산하지 않습니다.
- 독립 8셀 도깨비 아트에 네 걷기 프레임·대기·공격 준비·공격·피격을 적용하고 발 기준점을 고정합니다. 사망은 피격 자세와 별도의 소멸/퇴색 효과입니다. 기존 주민은 변경하지 않았습니다.
- .08초 전투 대상 히트 스톱(전역 time_scale 미변경), .1초 흰색 셰이더 피격 강조, .25초/최대 화면 10px 카메라 흔들림과 충돌 넉백, 12파편/.6초·위로 뜨는 숫자/.8초. UI CanvasLayer는 흔들리지 않습니다. 기본 공격 파랑/부적 금색, 사망 별도 소멸.
- `hit_config.gd`에 효과 시간·강도·개수를 분리하고 저장되는 개별 토글을 제공합니다. 파편/숫자/잔상은 상한을 두고 수명이 끝나면 제거합니다.

## 범위와 한계

첫 전투 임무를 실제로 끝낼 수 있는 프로토타입입니다. 새 상점 구매·승급 과제·추가 그림 스테이지·분신/축지·새 의상은 이번에 구현하지 않았습니다. 가방 아이콘은 글자 문양이며, 숲 바닥/바위/물은 절차적으로 생성한 임시 게임 아트입니다. 그림과 도깨비 아트는 새로 생성했고 대나무·석등은 기존 에셋을 재사용했습니다. 그림의 대나무 움직임은 별도 국소 레이어이며 원화 전체를 변형하지 않습니다.

실제 갤럭시와 Android 에뮬레이터는 이 환경에서 사용할 수 없습니다. 실기기 설치·소리 청취·OS 안전 영역·발열/60FPS 검증을 완료했다고 주장하지 않습니다. 아래 자동 검사는 Godot Linux 및 실제 APK 안에 포함된 리소스에서 수행합니다. 공개 GitHub의 표준 Ubuntu Actions를 재사용하며 별도 유료 서버/API를 만들지 않습니다.

Cloud APK는 1.3.0/code9, 약 68.5MiB로 생성되었고 실제 서명·API29/36·ARM64·가로·권한 없음·ZIP 무결성·16KiB 정렬과 새 리소스 포함 검사를 통과했습니다. 최종 설치 파일은 아래의 Actions 소스 컴파일 이후 기존 키로 서명한 파일을 사용합니다.

발소리 최종 대조: 광장 상점 앞마당과 정원 다리는 실제 베이크된 돌 재질로 판정합니다. 나무 소리는 실제 나무 판자를 그린 숲 입구 데크에서 재생됩니다.
