# 《도사》 V1.2 — 광장·NPC·타이틀 개선

## 보존과 범위

기존 Godot 4.6.3 stable / GDScript 프로젝트를 유지했습니다. 작업 전 V1.1 checkpoint APK 빌드가 통과했고, `backup/dosa-v1.1` 브랜치에 `89b5aa1`을 원격 보존했습니다. 새 저장소·프로젝트를 만들지 않았습니다.

게임 수정은 광장 배치·시각 효과, NPC 이동·애니메이션, 타이틀 국소 애니메이션 세 가지입니다. 플레이어 이미지·이동 속도·달리기·둔갑·기존 대화/퀘스트·그림 소개·잠금 상태·미니맵·음악/효과음·터치 조작을 유지했습니다. 전투·새 도술·그림 속 스테이지·상점 구매는 추가하지 않습니다.

Android versionName `1.2.0`, versionCode `8`, 패키지 `com.suspiciousfactory.game`, Android 10+ ARM64, 기존 서명을 유지합니다. 저장 스키마1·파일명·맵 ID는 유지하고, 재배치로 옛 좌표에 건물이 생긴 경우만 근처 안전 좌표로 이전합니다. 이전 좌표와 퀘스트·변신·그림 완료 데이터·귀환 좌표를 보존하는 revision-2→3 검사를 추가했습니다.

## 광장

- 잔디를 가로지르는 길 중심 배치 대신, 넓은 불규칙 돌바닥 광장·그림 장터 마당·연결된 상점 거리를 구성합니다. 지형 범위와 이동 가능 경계를 유지해 맵을 줄이지 않았습니다.
- 한옥·주막·노점·부적방·도구점·잡화점·창고를 광장과 거리의 앞마당을 따라 모았습니다. 기존 에셋을 재사용하고 현관 진입로·장독·수레·노점·석등·상품 진열을 배치합니다.
- 중앙 벚꽃나무를 시각 중심으로 옮기고, 작은 벚나무는 열린 동선에서 가장자리로 옮깁니다. 캐릭터 카메라 목표를 36단위 위로 조정하되 Camera2D offset은 0을 유지해 경계를 벗어나지 않게 합니다. 확대율 2.0과 터치 버튼 크기는 유지합니다.
- 그림 장터에 별도의 포장 색·문양·푸른빛·제한된 마법 입자·흔들리는 종이 부적을 적용합니다. 중앙 나무의 약한 금빛, 밤의 작은 푸른 불빛, 등불 밝기의 미세한 변화를 추가합니다. 기존 완료 보상용 나무 기억 표시와 주변의 장식 빛은 구분합니다.
- 입자·그림 애니메이션·환경 효과는 기존 ‘환경 효과 간소화’ 설정을 따릅니다. 실시간 PointLight2D는 추가하지 않았습니다. 지형은 개발 시점에 렌더링해 단일 바닥 텍스처로 표시하고, 충돌은 독립 데이터로 유지합니다.

## NPC 원인: 실제 코드와 V1.1 실행 측정

기존 Actor는 매 물리 틱마다 원점 주위 폭 28×높이16인 타원의 이동 목표를 다시 계산했습니다. 3단위 도착 판정 경계에서 이동/정지를 반복하며, 의도 속도도 `24×0.3=7.2`로 매우 느렸습니다. 목적지까지 걷고 쉬는 상태가 없었습니다.

기존 그림은 ‘대기’와 ‘한 발 내민 자세’ 두 장을 교체했고, facing은 계산해도 NPC 그림에 사용하지 않았습니다. 자세별 알파 바운딩박스에서 만든 발 중심은 가방·옷·발 모양의 변화에 따라 달라졌습니다. 상인의 origin 보정만으로 1.89월드 단위(카메라 확대율2에서 약 3.78픽셀) 차이가 생겼습니다.

V1.1 APK 리소스를 별도 프로세스에서 실행한 결과: 게임 시간40초 동안 상인의 이동/정지 전환 **402회**, 원점에서 최대 이동13.62단위, 스프라이트 기준점 보정 차이3.78화면 픽셀입니다. 이는 Linux headless의 실제 Actor 측정이며 Android 실기기 측정은 아닙니다.

## NPC 해결

- 고정 목적지·대기·걷기·상인 작업·플레이어 주목을 별도 상태로 처리합니다. 도착하면 미세 목표를 계속 좇지 않고 실제로 정지합니다. 플레이어 주목 거리에 이력(48/70단위)을 두어 경계에서 상태가 반복되지 않게 했습니다.
- 주민·상인·어른·스승마다 이동 지점·속도·대기 시간을 달리합니다. 주민은 넓게 산책하고, 상인은 자신의 진열대 근처를 오가며 팔 동작을 합니다. 어른은 천천히 걷고 오래 쉬며, 수련 관련 NPC는 수련소 범위에 머뭅니다. 주민이 가까이 모였을 때 잠깐 양보하는 대기도 있습니다.
- 기존 3종 NPC의 외형을 참고한 **24셀 걷기 시트**(3종×앞/뒤×4프레임)를 추가했습니다. 앞/뒤 시점과 좌우 반전으로 이동 방향을 표현합니다. 플레이어의 기존 8방향 시트는 바꾸지 않았습니다.
- 머리 영역과 몸통·다리·두 발을 분리해 기준점을 고정하고, 다리 프레임과 좌우 발의 접지/스윙을 번갈아 적용합니다. 캐릭터 전체를 흔들어 걷는 척하지 않습니다. 발 주기는 실제 이동 거리로 진행하며, 멈추거나 장애물에 막히면 대기 자세로 전환합니다.
- 정적인 충돌 데이터에 대해 미리 계산한 882개 지점·3040개 연결을 재사용합니다. 경로 탐색은 목적지를 고를 때만 수행하며 매 프레임 재탐색하지 않습니다. 벽에 막혀 진행이 없으면 0.65초 뒤 대기 후 다른 목적지를 고릅니다.
- 정적 건물·나무·울타리·진열대·물 충돌은 유지합니다. NPC와 플레이어 사이의 밀기 충돌은 추가하지 않습니다. 플레이어가 가까이 오면 NPC가 멈춰 기존 대화를 제공합니다.
- 화면 밖에서는 불필요한 스프라이트 갱신을 생략하고, 플레이어와 850단위 이상 떨어진 NPC는 이동·경로 재계산·애니메이션을 멈춥니다.

## 타이틀

원본 `assets/woo/hd/title.png`는 하나의 완성된 이미지입니다. 파일을 수정하지 않고 유지했습니다. 기존 전체 이미지의 줌·패닝 셰이더는 제거했습니다.

- 손 위치에 고정된 파랑·보라 입자와 회전 궤도, 미세한 광량 변화, 짧은 국소 번개를 추가합니다. 화면 전체 플래시는 없습니다.
- 크기·이동 속도·회전이 다른 원근 꽃잎을 제한된 개수로 반복합니다. 생성/재생성은 화면 바깥에서 처리하며 버튼과 얼굴을 과도하게 가리지 않습니다.
- 폭포 3곳의 물 부분에만 아래 방향 UV 흐름을 적용합니다. 절벽·인물·전체 배경을 함께 움직이지 않습니다.
- 강물 반사광의 미세한 수평 흔들림, 강 위의 독립적인 옅은 물안개, 구름 영역의 느린 국소 움직임을 적용합니다. 달 위치는 고정하고 밝기만 아주 조금 변합니다.
- 기존 네 메뉴와 터치 영역은 고정합니다. 누른 금빛 테두리가 밝아졌다가 약하게 사라지는 효과를 기존 정상 화면 전환에 더했습니다.
- **갓 끈·옷자락 변형은 생략했습니다.** 단일 원본에서 깔끔한 레이어 분리가 어려워 얼굴·몸·의상 그림을 억지로 왜곡하지 않는 쪽을 택했습니다. 입체 의상 시뮬레이션이나 별도 리깅을 구현했다고 주장하지 않습니다.

## 검증과 한계

필수 checkpoint는 기존 검사259개와 NPC/타이틀 검사38개(총297개), 종료/재시작 경로, APK 검사26개를 수행합니다. 새 검사는 대기 위치 고정·세 NPC 외형의 머리 기준점 고정·4개 다리 프레임·좌우 발 교대·NPC8명 실제 순찰·장애물 대기·화면 밖 처리·버전 이전을 포함합니다.

렌더링 검사는 별도 OpenGL 프로세스에서 타이틀 두 시점, 네 가지 발걸음 자세, 수정한 다섯 구역을 캡처합니다. 실제 Android OS·갤럭시 실기기 실행, 발열과 60FPS 보장은 검증하지 못했습니다. 데스크톱 소프트웨어 OpenGL 결과를 갤럭시 FPS로 주장하지 않습니다.

## GitHub Actions와 서명

기존 연결은 저장소/Actions 사용이 가능하지만 서명 비밀값 조회 API에403을 반환했습니다. 새 설치 키를 만들거나 기존 개인키를 공개 저장소에 올리지 않습니다.

기존 Android checkpoint 워크플로에 unsigned 중간 빌드 경로를 추가했습니다. CI는 도구상 필요한 일회용 임시 서명으로 컴파일·검사한 다음, 해당 서명을 완전히 제거한 중간 APK만 올립니다. 그 파일을 Cloud에서 정렬하고 기존 지속 서명키로 서명해 설치 가능한 최종 APK를 만듭니다. 기존 키와 인증서가 같은지 검사하고, 기존 전달 워크플로로 최종 APK 아티팩트를 제공합니다. 임시 CI 키는 사용자에게 설치할 APK의 키가 아닙니다.

비밀값이 없는 경우에도 자동 CI는 unsigned 중간 빌드로 게임·회귀 검사를 수행합니다. 서명되지 않은 중간 파일은 설치용으로 안내하지 않습니다. 기존 지속 키가 CI에 설정된 경우에는 원래 직접 서명 경로도 유지합니다. 이번 실행 결과·해시·다운로드 링크는 검증 후 아래에 기록합니다.
