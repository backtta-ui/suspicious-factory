# 2.0.13 — 저장된 꾸미기에서 원본이 깨지는 오류

앞선 2.0.12는 기본 차림과 모든 필드가 일치할 때만 원본을 사용했다. 장신구나 색상 한 항목만 달라도 64px 몸체·헤어·모자를 조립하던 이전 렌더러로 돌아갔다. 사용자 사진의 큰 모자와 다른 얼굴은 이 경로로 재현된다. 기본 차림만 검사한 이전 수정은 충분하지 않았다.

## 수정한 내용

- 조건부 원본 적용과 이전 몸체/헤어/모자 합성 경로를 렌더러에서 제거했다. 저장된 어떤 조합이든 원본 캐릭터의 얼굴·신체 비율·기본 모자·의상을 유지한다.
- 장신구 변경이 캐릭터 전체를 교체하지 않는다. 추가 장신구는 발 기준 허리/등 앵커를 사용하고 폭을 5월드 단위로 제한한다. 부위와 방향에 맞춰 앞뒤 순서를 정한다.
- 의상 색상은 원본 PNG를 교체하지 않고 의상 영역 마스크로만 변경한다. 얼굴·머리·모자 영역에는 색상 마스크가 없다.
- 원본 PNG와 원본 생성 이미지는 수정하거나 재생성하지 않았다. 저장된 선택 ID와 보유 기록도 변경하지 않는다.
- 기본 스타일의 이전 ID 명칭과 실제 원본 외형이 다른 부분은 UI에서 ‘원본 머리/원본 갓/원본 두건/원본 색상’으로 표시한다.

## 중요한 미완료 범위

원본은 모자·머리·의상이 합쳐진 완성 이미지다. 교체에 필요한 독립 원본 레이어가 없는 상태에서 기존 합성 에셋을 원본과 호환되는 것처럼 표시할 수 없다.

따라서 **교체용 헤어·모자·의상은 원본 리소스 준비 중으로 비활성화**한다. 기존 소유권과 저장 ID는 그대로 두며, 해당 부위는 원본 차림을 표시한다는 안내를 보여준다. 모자 교체 전체가 완성됐다고 보고하지 않는다. 이 업데이트에서 실제 제공하는 것은 모든 저장 조합의 원본 캐릭터 유지, 추가 장신구 및 원본 의상 색상 변경이다.

전용 걷기·공격 연속 프레임과 원본 기반 교체용 헤어·모자·의상 제작은 남아 있다. 부족한 리소스를 임시 합성으로 숨기지 않는다.

## 검증

- 장신구·색상·방향·캐릭터 조합, 원본 렌더러 유지, 추가 장식 크기, 얼굴 영역 색상 보호: **8,418 검사 통과**.
- 전체 저장 조합 검사는 모든 의상·헤어·모자 ID를 포함하도록 확장했다. 미지원 항목은 정상 지원으로 취급하지 않고 원본 표시와 저장 보존을 검사한다.
- 기존 저장 형식·소유권·캐릭터 해금·게임 규칙은 변경하지 않았다.

실제 렌더링 픽셀 비교에서도 기본 차림과 장신구/색상 변경 화면의 얼굴·갓 영역(140×132px)이 동일했다. [비교 JSON](render-comparison.json), [비교 기준 화면](native-baseline.png). 이는 기본 차림에만 원본을 쓰는 오류가 다시 생기는지 확인하는 검사다. 미지원 모자를 실제 착용했다는 의미는 아니다.

## 로컬 최종 체크포인트

- `jeon-woochi-2.0.13.apk`, versionCode 24, 131,681,481 bytes.
- SHA256: `2c44c79259eac4ac4a48580988490d07c847747c15322f11c64fb453fd6b692a`.
- 기존 패키지와 서명키 유지. 기존 앱을 삭제하지 않고 업데이트 설치해야 한다.
- 실제 갤럭시 기기 테스트는 수행하지 않았다.

완전한 교체 기능에 필요한 리소스: 원본 디자인의 몸체/얼굴, 앞·뒷머리, 모자, 의상을 각각 분리한 투명 레이어와 방향별 피벗·모자 아래 헤어 마스크. 현재의 합쳐진 PNG에는 가려진 부분의 픽셀이 없으므로 코드만으로 해당 부분을 복원할 수 없다. 원본을 임의로 재생성하거나 부정확한 합성으로 완료 처리하지 않았다.
