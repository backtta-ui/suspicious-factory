# 광장·그림 세계 개편 — 2.0.6 (V2.0 유지)

기존 Godot 4.6.3 / GDScript / Android 프로젝트를 유지한다. 패키지·기존 서명·기존 캐릭터와 꾸미기·도술 도감·오프라인 수련장·숲 전투·아이템/보상 기록을 보존한다. 작업 전 백업은 `backup/dosa-2.0.5-before-painting-worlds`이다. 멀티플레이 규칙, 서버, 멀티 맵은 이번 변경에 포함하지 않는다.

## 조사와 구조

기존 `village_layout.PAINTINGS`의 세 ID는 저장 검증에서 사용하고 있었지만 실제 입장은 `adventure.load_forest` 하나뿐이었다. 기존 두 미출시 그림 데이터는 삭제하지 않고 레거시 기록 검증용으로 보존했다. 광장 실물 배치만 1개로 통합하고, 새 `worlds/catalog.gd`에서 여우의 숲/달빛 궁궐/붉은 달의 바다를 관리한다. 기존 숲의 임무와 보상 조건은 바꾸지 않는다.

## 실제 구현

- 광장의 길/돌마당 가장자리에 흙·이끼·풀·자갈 변형을 결정적으로 배치해 기존의 딱 잘린 경계를 완화했다. 돌 패턴 좌표 변형을 늘리고 숲길 색상을 흙/돌의 따뜻한 색상으로 맞췄다. 바닥만 오프라인 렌더링으로 굽고, 건물·나무·물·상호작용·충돌은 독립 오브젝트로 유지한다. 기존 광장 배치와 수련장 입구는 보존했다.
- 광장 그림 실물은 `(1900,350)`의 큰 그림틀 1개다. 접근 후 ‘그림 세계’를 누르면 전체 화면 선택기가 열린다. 장면을 걸어 다니는 전시관이 아니다.
- 데이터 기반 목록, 좌우 스와이프, 이전/다음 버튼, 그림명/설명/번호, 입장, 닫기, Android 뒤로가기를 연결했다. 0.24초 슬라이드 중에는 중복 변경/입장을 막는다.
- 여우의 숲: 기존 3000×2160 이동 공간, 도깨비 3마리·전투·사당 퍼즐·확정된 보상·고양이 형상 획득 조건 유지. 길과 자연 지형 경계를 개선했다.
- 달빛 궁궐: 별도 1800×1300 공간에 왕궁 정문/본전/측면 전각/담장/돌계단·정원·등불·문양 지점을 배치했다. 실제 장애물과 경계 충돌이 있다.
- 붉은 달의 바다: 별도 1800×1300 해안에 다각형 이동 경계, 절벽/젖은 바위/해안 정자/제단을 배치했다. 이동 불가능한 바다·외곽은 경계 충돌로 막는다. 바다에는 색상 변화·붉은 반사광·국소 물결·해안 포말 애니메이션을 적용했다.
- 두 새 맵은 각각 3개 문양의 짧은 탐험·상호작용을 제공한다. 정답 문양을 맞추면 발견 기록만 저장하며, 미확정 도술이나 아이템 보상은 지급하지 않는다. 새로운 복잡한 전투/스토리/RPG 성장은 추가하지 않는다.
- 실제 캐릭터를 재사용해 맵 간 재부모화하며 복제 플레이어를 생성하지 않는다. 진입 직전 광장 위치·방향·카메라 줌/회전/로컬 위치를 저장해 복귀한다. 기존 저장에 카메라 필드가 없으면 안전한 기본값을 쓴다.
- 새 맵 세션도 기존 RPG 저장의 검증 허용 목록에 추가했다. 새 궁궐/해안에서 저장·앱 재시작·이어하기를 지원하며 기존 숲의 처치/보상 데이터 형식은 유지한다.
- 새 맵에서도 미니맵, 이동/점프/비전투 둔갑술, 가방/메뉴, 도감의 수련장 왕복을 유지한다. 두 새 맵에는 전투 UI를 활성화하지 않는다.

## 에셋과 성능

기존 한옥·벚꽃·대나무·등불·연못·다리·우물·장터를 재사용했다. 새 `worlds/props.png`는 왕궁/해안용 독립 소품 8개의 픽셀 아트 시트다. 바닥 2개와 그림 미리보기는 실제 오브젝트 맵을 오프라인 렌더링한 결과다. 런타임 맵을 한 장의 완성 배경 그림으로 대신하지 않는다. 정적 바닥은 1회 텍스처 그리기, 동적 환경 효과는 10~20Hz 갱신과 제한된 입자/물결을 사용한다.

새 맵은 짧은 탐험의 첫 구현이다. 장편 스토리, 신규 도술 보상, 새로운 NPC 서사/전투는 미확정·미구현이다. 궁궐/해안의 추가 소품·타일 전환·파도 미술 다듬기는 후속 개선 여지가 있다. ‘상업 게임 수준 미술 완성’이나 갤럭시 60FPS 달성을 검증한 것으로 보고하지 않는다.
