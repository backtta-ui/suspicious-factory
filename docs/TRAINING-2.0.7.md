## 캐릭터

네 캐릭터의 대각선 core/action과 헤어 앞/뒤·모자·장신구·백월/흑야 의상 총16개 동반 아틀라스, 344개 방향 프레임을 추가했다. 기존 정면/후면/측면 344프레임은 유지한다. 몸체와 장비는 같은 방향 인덱스를 사용한다. 픽셀 검사로 추출한 발/머리/목 기준 메타데이터를 사용하며 원본 이미지는 변형하지 않는다. 조이스틱 방향에는 각도 히스테리시스를 적용한다. 꾸미기 방향 미리보기도8방향으로 확장했다.

**제한:** 새 원화 일부의 대각선 장식·얼굴 각도와 기존 원화의 픽셀 밀도가 아직 완전히 균일하지 않다. 모든 조합의 미술적 완성을 자동 검사로 증명할 수 없다. 기존 리소스 미지원 의상5종은 여전히 준비 중이며 소유/저장 ID를 유지한다. 실제 리소스 없이 완성되었다고 표시하지 않는다.

## 수련장

작은 상단 정보, 별도 설정 메뉴, 원형 조작3개, 버튼 쿨타임, 문맥별 변신 해제. NPC 가까운 대상에만 HP 우선 표시, 가까운 이름표 간격 보정. 목록은 제목/상세/선택·닫기 고정, 가운데만 터치 스크롤한다. 드래그 중 선택을 억제하고 배경 이동을 중지한다. 범위는 조준 버튼을 누르거나 설정에서 잠시 확인할 때만 표시한다. 기존 바닥에 구워져 있던 큰 노란 원도 제거했다.

추적부의 원형 점을 좌우 신발 밑창 리소스로 변경했다. 먹 연기·장막·호신부·해봉술·천면술·혼불·발동/이동 효과는 개별 스프라이트를 사용한다. 모든 도술이 상용 수준의 완성된 다중 프레임 이펙트를 갖췄다는 의미는 아니다. 지속 효과의 전개·소멸과 발동 효과가 구현되어 있으며 세밀한 후속 원화 작업은 남아 있다.

고양이32×25, 강아지36×29, 닭23×25(world units)로 종별 가독성을 개선하고 투명 여백을 제외한 원화 영역을 사용한다. 원본 동물과 둔갑 형태는 같은 렌더러를 사용한다. 기존4프레임 보행 유지. 허수아비/등불도 실제 원화 영역 기준으로 표시한다. **여우 신규 애니메이션, 동물별 앉기/뛰기, 모든 생활소품의 고급 원화, 전체 환경 충돌 재설계는 미완료**다. 온라인 맵의 충돌 크기와 이동 규칙은 임의로 변경하지 않았다.

## 갤럭시에서 다운로드

[서명된 APK Actions 실행 43961464239](https://github.com/backtta-ui/suspicious-factory/actions/runs/43961464239) 성공. GitHub 로그인 → 아래 **Artifacts → jeon-woochi-verified-apk** 다운로드 → 삼성 내 파일에서 ZIP 압축 풀기 → `jeon-woochi-2.0.7.apk` 실행. 기존 앱을 삭제하지 말고 덮어 설치한다.

Release 대용량 파일 업로드가 uploads.github.com 인증401로 실패했다. 새 저장소나 유료 서비스 없이 기존 `apk-downloads` 브랜치에100MiB 미만의 검증된 조각으로 보관하고, Actions가 재조립/전체 SHA 검증 후 **하나의 설치 APK**를 제공한다. 휴대폰 이용자는 조각 파일을 직접 합칠 필요가 없다. 이전 APK 파일도 그대로 보존했다. 배포 커밋 `94053ae229c19ece900f544b020c4f188f5e44c3`.

공개 HTTPS 조각 재다운로드/재구성 해시 검사와, Actions 아티팩트14275345544 ZIP 재다운로드 후 내부 APK 해시 검사 모두 원본과 일치했다. 이 전달 실행은 기존 Cloud 서명 APK를 검증해 제공하는 작업이며 소스 재컴파일과 구분한다.

[별도 GitHub 소스 빌드 43960559885](https://github.com/backtta-ui/suspicious-factory/actions/runs/43960559885)는 기존 워크플로로 테스트·APK 컴파일·검증에 **성공**했다. CI의 임시 서명은 제거되므로 설치는 위 **서명된 APK** 아티팩트를 사용한다. 이전 중간 실행43960048069는 최종 방향 보정 커밋으로 검증 대상을 옮기며 취소했다; 빌드 실패로 기록하지 않는다.

Actions 아티팩트 보관 기간은14일이다. 이후 같은 전달 워크플로를 다시 실행하면 배포 브랜치의 보존 파일에서 동일 SHA APK를 재생성할 수 있다. 실기기 검증·지속60FPS·모든 에셋의 미술적 완성은 미완료로 유지한다.
