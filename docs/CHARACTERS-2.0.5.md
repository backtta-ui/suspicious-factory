# 《도사》 캐릭터 구조 수정 — 2.0.5 (V2.0 유지)

## 실제 원인

기존 `hd/hero.png`에는 전우치 방향별 전신이 있었지만, HeroRig가 한 대기 행을 잘라 팔다리를 회전시키고 있었다. 다른 세 도사의 wardrobe 에셋은 정면 부품뿐이었다. 정면 의상 위에서 얼굴/머리만 바뀌므로 전신 방향 전환을 구현할 수 없었다. 단일 `appearance` 저장과 캐릭터 변경 시 장비 유지 동작도 이번 요구의 캐릭터별 기본 차림/독립 저장과 달랐다.

기존 코드/원본/보유 기록을 보존하고 별도 방향 리소스를 추가했다. 작업 전 백업: `backup/dosa-2.0.4-before-character-rebuild` (623ee2c).

## 구현

- 전우치: 남색 도사복/검은 머리/검은 갓. 연화: 연보라 도사복/갈색 꽃 머리. 무영: 은백 머리/먹색 도사복. 홍련: 붉은 도사복/긴 검은 머리/붉은 허리 장식.
- 각 캐릭터에 실제 정면/후면/왼쪽/오른쪽 전신을 제작했다. 각 방향에 대기, 두 걷기 접지 자세, 점프 자세, 서로 다른 4타 자세, 도술, 피격/착지 자세가 있다. 기본 차림은 완성형 atlas를 직접 사용한다.
- 공통 Renderer가 같은 캐릭터의 깨끗한 얼굴/머리 기준점을 사용한다. 의상만 바꾸면 그 캐릭터 얼굴을 유지하며, 네 방향의 실제 새 의상 동작 리소스를 연결한다. 다른 캐릭터 얼굴/몸통을 가져오지 않는다.
- 앞/뒷머리, 얼굴형 모자/머리형 모자, 장신구는 각 방향별 에셋을 사용한다. 눈 보호/모자 안쪽 헤어 마스킹, 소품 앞뒤 순서와 실제 머리/발/목 기준점을 적용한다. 좌우 방향도 별도 리소스이며 이미지 반전으로 대신하지 않는다.
- 조이스틱의 마지막 방향을 유지한다. 대각선은 인접한 마지막 4방향을 우선해 방향 떨림을 줄인다. 이동 거리와 걷기 주기를 연동하며 네트워크/수련장/도감 체험에도 같은 기준을 적용한다.
- 공통 렌더러는 광장, 모험, 옷장 미리보기, 수련장, 멀티 아바타, 복제 외형에 적용된다. 잔상도 실제 렌더링 레이어를 재사용한다.
- 프로필 v2: `per_character`에 개별 외형 저장. 기존 v1 look은 그 캐릭터에만 이관하고 보유 목록/서버 승리 기록을 유지한다. 다른 캐릭터는 자신의 기본 차림으로 시작한다. 임시 미리보기 변경은 취소 시 저장되지 않는다.
- Android 패키지/서명키/최소 API/가로 화면/기존 게임 저장은 유지한다. versionName 2.0.5, versionCode 16.

## 에셋 현황과 남은 작업

원래 네 캐릭터 중 전우치만 방향별 원본 전신이 있었다. 새 리소스는 소스 시트 16개(344 프레임) + 기본 차림 조립 시트 8개(160 프레임)다. 생성 원본의 행 높이가 균등하지 않아 전체 픽셀 경계와 몸체 성분을 측정한 source region을 사용한다. 팔이 얼굴에 닿은 자세에서 머리 높이 오측정이 생기는 것도 분리해, 네이티브 머리 폭 기준으로 원본 픽셀 밀도를 맞추고 기본 전신 atlas로 굽는다. 런타임 점프 스케일 변화와는 별개다.

**지원 의상: 기본/백월/흑야 3종.** 도깨비/청풍/설화/천상/황룡 5종은 방향별 동작 리소스가 없으므로 선택을 비활성화했다. 소유권/기존 저장 ID는 제거하지 않는다. 이전 저장이 이 의상을 가리키면 준비 중 안내와 기본 도사복을 표시한다. 모든 8종 의상이 완성된 것으로 보고하지 않는다.

4방향이며 8방향 완성 에셋은 없다. 걷기는 두 접지 자세와 중립 연결이며, 점프는 한 준비된 자세와 실제 높이 물리, 피격/착지는 한 공유 자세다. 모든 세부 점프 단계나 연속 다프레임 상업 수준 애니메이션이 완성된 것은 아니다. 일부 머리카락 끝/방어 자세 신발 등 생성 원본 가장자리에는 추가 픽셀 아트 다듬기가 남아 있다. 기존 전우치 디자인을 참고한 새 방향 리소스이며 원본과 픽셀 단위로 동일한 외형은 아니다.

## 검증과 배포

최종 검증 수치/CI/서명/APK 다운로드 링크는 동봉 JSON 및 아래 최종 결과를 참조한다. 로컬 자동 입력과 실제 소켓 테스트는 실기기 멀티플레이 테스트와 구분한다. Galaxy 설치·터치·프레임은 사용자 실기기 확인이 필요하다. 앱을 삭제하지 말고 기존 앱 위에 업데이트 설치해야 로컬 기록을 유지할 수 있다.
