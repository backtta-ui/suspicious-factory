# 도사 꾸미기 후속 업데이트 2.0.1

기존 저장소·Godot4.6.3/GDScript·패키지·서명·Android10+/ARM64/가로 화면·V2.0 모험과 멀티 코드를 보존했습니다. 변경 전 상태는 `backup/dosa-v2.0-customization`(31326b0)에 보관했습니다. 후속 APK는 2.0.1/코드12입니다.

## 사용법과 실제 적용

타이틀 왼쪽 **도사 꾸미기**, 또는 플레이 중 메뉴 → 의상에서 옷장을 엽니다. 캐릭터·헤어·의상·모자·장신구·색상 탭에서 즉시 미리 보고 **저장 및 돌아가기**를 누릅니다. 취소와 Android 뒤로가기는 저장하지 않습니다. 잠긴 항목도 감상할 수 있지만 저장은 막습니다. 미리보기에서 방향·걷기·점프·공격을 확인할 수 있습니다.

전우치와 연화는 무료입니다. 무영은 여우의 숲 완료, 홍련은 여우의 숲 사당 문양 퍼즐 완료로 해금됩니다. 기존 완료 저장도 인식합니다. 헤어6종·모자6종과 미착용·장신구8종과 미착용·의상8종의 개별 이미지가 있으며, 의상별 지원 색상 목록을 사용합니다. 기본 도사복은 시작 시 제공하고 흑야/도깨비 도복은 실제 여우의 숲 임무 보상입니다. 백월/청풍은 동일 서버의 확정 누적10/30승입니다. 이벤트 설화·마스터 천상·상품 황룡은 준비 중 잠금이며 구매 기능이 없습니다. 테마 의상은 향후 카탈로그 확장 대상으로 남깁니다.

기존 전우치의 기본 설정은 원본 이미지·피벗·배율을 그대로 사용합니다. 커스텀 설정은 얼굴·머리·의상 몸통/소매/옷자락·모자·장신구를 독립 합성하고 같은 이동/공격/점프 상태를 따릅니다. 의상은 서로 다른 원화와 실루엣이며 색상만 바꾼8벌이 아닙니다. 몸체 색상 셰이더는 얼굴·모자·장신구와 분리합니다. 모자별 위치를 보정하고 머리 앞부분을 제한하여 눈과 모자를 덜 가리도록 했습니다.

장식은 허리 위치를 따라가며 충돌·이동 속도·HP·공격력·시야·도술 수치를 변경하지 않습니다. 저장한 설정은 광장·그림 속 모험·멀티 대기실/게임/결과에 적용합니다. 요괴에게만 보이는 장식은 없으며 둔갑/외형 복제는 일반 장비 데이터와 별도로 처리합니다. 서버가 대전 중 외형 변경을 거부합니다.

## 공격과 움직임 수정

기존 공격은 시작 때 `facing`을 고정하고 공격 중 조이스틱 방향 갱신을 차단했습니다. 이제 조이스틱이 우선하는 방향으로 공격을 시작하고 타격 전까지 조준을 갱신합니다. 타격 후 피해 방향은 유지하여 이미 맞힌 판정을 뒤집지 않으며, 다음 예약 콤보는 새 방향을 따릅니다. 실제 왼쪽 적 피해와 오른쪽으로 바꾼 다음 콤보를 검사합니다.

발동작은 프레임 시간만이 아니라 실제 이동 거리와 출발/정지 가중치를 사용합니다. 광장 둔갑 아이콘의 `SkillBadge`에 실제 쿨타임과 최대값을 전달해 원형 게이지·남은 시간·사용 가능 발광을 표시합니다. 기존 코드는 글자는 갱신했지만 아이콘 게이지 값은 전달하지 않았습니다.

새로운 장타·금빛 부적·보라 봉 타격·청룡파의16프레임 아틀라스와 가산 합성·국소 중립색 제거 셰이더를 적용합니다. 기존 타격 정지·하얀 피격·넉백·파편/데미지 숫자와 설정은 유지합니다. 동시에 남는 효과 노드는24개로 제한합니다. 상업 게임 수준의 품질이나 Android60FPS를 검증 완료했다고 주장하지 않습니다.

## 저장과 승리 보상

`dosa_wardrobe.json`을 별도로 추가해 기존 RPG 저장 스키마/아이템/레벨을 초기화하지 않습니다. 외형6ID·보유 항목·서버별 승수·확인 승수를 보관하고 임시 파일→교체와 이전 정상 파일 백업을 사용합니다. 잘못된 ID는 기본값으로 정규화하며 미보유 조합은 저장할 수 없습니다. 외형 도감은 ID 기반이므로 캐릭터·상품을 확장할 수 있습니다.

멀티 승수는 서버가 결과 확정 시 승리 진영의 접속 참가자에게 한 번 지급합니다. 도사/요괴 승리를 모두 인정하고, 클라이언트가 승수·결과를 보내서 늘릴 수 없습니다. 서버의 인증 해시·승수는 `user://seal_server_career.json`에 저장합니다. 같은 결과 재처리와 같은 누적 승수 재수신은 보상을 중복 지급하지 않습니다. 기존 클라이언트의 옛 `wins` 기록은 삭제하지 않지만 서버에서 재확인할 수 없는 예전 기록을 새 서버 검증 보상으로 소급 인증하지 않습니다.

무료 Render 재배포 시 로컬 서버 파일이 사라질 수 있습니다. 앱은 이미 획득한 장비와 서버별 확인 기록을 유지하지만 새 서버에서 승리 조건을 다시 확인하지 못하면 승리 의상 착용을 거절할 수 있습니다. 서로 다른 개인 서버의 기록을 공통 계정처럼 합산하지 않습니다. 안정적인 전역 승수·기기변경 복구에는 영속 저장/계정 검증이 필요하며 이번에는 유료 저장소나 결제를 도입하지 않았습니다. 모험 보상은 기존 오프라인 저장을 신뢰하므로 개조된 로컬 저장에 대한 서버 인증 체계는 아닙니다.

## 실제 구현 방식의 한계

추가 아트는 프로젝트용으로 생성한32부품 아틀라스와16효과 프레임입니다. 모든 새 캐릭터마다8방향의 완전한 전신 원화 프레임을 별도로 제작한 방식은 아닙니다. 공유 관절 리그, 좌우 반전·후면 처리와 원본 하체 동작을 사용합니다. 따라서 방향에 따른 장신구 원근감과 일부 포즈는 추가 미술 보정이 가능합니다. 이벤트·마스터·유료 상품·기기변경 복구는 미구현입니다.

## 검증과 빌드

`bash tools/checkpoint.sh`가 기존 회귀 테스트와 새 `wardrobe`·`server_rewards`, 실제 WebSocket 외형 동기화/대전 변경 거부, APK 서명·정렬·버전·리소스 검사를 수행합니다. Linux 실제 렌더러로 옷장·캐릭터·장식·효과를 캡처했습니다. 최종 빌드 결과는 배포 증거에 기록합니다. **갤럭시 실기기, Render 공개 서버, 실제6~8대의 꾸미기 동기화·장시간 성능은 미검증입니다.** 기존 무료 배포 안내의 서버를 새 소스로 수동 재배포해야 새 외형이 전송됩니다.
