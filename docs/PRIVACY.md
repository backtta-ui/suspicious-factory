# 2.0.2 테스트 개인정보 안내

그림 속 모험은 오프라인이며 봉인의 밤은 사용자가 입력한 서버에 접속합니다. 회원가입·광고·인앱결제·분석 SDK·원격 충돌 수집은 없습니다. 멀티플레이에 Android Internet 권한을 사용합니다. 서버 주소는 신뢰하는 주소만 입력하세요.

멀티 접속 시 익명ID·인증 비밀값(공개 인터넷에서는 TLS)·닉네임·외형ID·이동·도술·미션·투표·채팅 입력을 해당 서버에 전송합니다. 서버는 연결 IP를 처리할 수 있습니다. 경기 상태는 서버 메모리에, 익명 인증 해시와 확정 승수는 서버 전용 파일에 저장합니다. 호스팅 재배포로 서버 파일이 사라질 수 있습니다. 다른 참가자에게 필요한 공개 외형·근처 위치·닉네임·채팅을 표시합니다. 개인 역할은 구분하여 전송합니다. 호스팅 운영자는 Render의 로그 보관 정책을 별도로 확인해야 합니다.

꾸미기 외형·보유 항목·서버별 확인 승수는 별도 앱 전용 `dosa_wardrobe.json` 및 이전 정상 파일 백업에 저장합니다. 기존 모험 저장을 변경하거나 서버로 전체 전송하지 않습니다. 계정·구매·클라우드 복구 기능은 없습니다.

2.0.2의 짧은 그림 수련은 서버가 위치·문양 입력을 검증하며 획득 도술을 서버 전용 기록에 보관합니다. 앱은 서버별 발견 기록과 서명 체크포인트를 저장하고 재접속 시 해당 서버에 제출할 수 있습니다. 체크포인트에는 익명ID·인증 해시·습득 도술·승수만 포함하며 결제 권한은 포함하지 않습니다. 서버 서명 키는 서버 환경변수/전용 파일에만 두며 앱에 포함하지 않습니다. 서버와 기기의 키·기록을 모두 잃은 경우 자동 계정 복구는 없습니다.

익명ID·재접속 비밀값·주소·장착·플레이 기록은 별도 앱 전용 `seal_identity.json`에 저장합니다. 비밀값을 화면이나 일반 로그에 표시하지 않습니다. 앱 삭제/데이터 삭제 후 계정·기기변경 복구 기능은 없습니다.

위치·맵·설정·도술 해금·변신 상태·마을 시간은 앱 전용 기기 저장소에만 저장합니다. 파일은 `jeonwoochi_save.json`, `jeonwoochi_settings.cfg`입니다. 자동 Android 백업을 끄며, 앱 데이터 삭제나 제거로 로컬 데이터가 삭제됩니다.

디버그 입력 진단은 좌표와 버튼·화면 상태를 크기가 제한된 로컬 파일에 기록합니다. 외부로 전송하지 않으며 release 빌드에서는 기본 비활성화됩니다.

정식 Google Play 출시 전 운영자 연락처와 공개 정책을 확정해야 합니다.
