# V0.1.1 참고 이미지 기반 그래픽·UI 개편

사용자가 제공한 두 이미지의 달빛·벚꽃·푸른 안개·호박빛 등불·금빛 테두리를 기준으로 메인 메뉴와 실제 플레이 화면을 바꿨습니다. 기존 도사 V0.1 기능과 공장 백업, 저장소, 패키지·서명키를 유지했습니다.

## 실제 변경

- 타이틀은 새 일러스트 배경과 별도의 한글 제목·실제 버튼으로 구성합니다. 계속하기 비활성 여부, 설정·종료 기능을 유지합니다.
- 플레이 화면은 한 장의 배경으로 대체하지 않습니다. 기존 지형·충돌·Y 깊이 정렬 위에 분리된 한옥·우물·장터·벚나무·등불 아틀라스를 표시합니다.
- 도사는 8방향×6행의 새 48프레임 시트로 걷기·달리기·대기·눈깜박임을 표시합니다. 주민과 항아리에도 새 리소스를 적용합니다.
- 원본 생성 PNG는 편집하지 않고, 별도 프레임 사각형과 발 기준점 데이터로 표시합니다. 머리·옷·그림자의 기준점이 이동 때 어긋나지 않도록 했습니다.
- 금빛 모서리 버튼, 원형 달리기·상호작용·둔갑술 버튼과 조이스틱, 초상·위치 표시를 적용했습니다. 실제 기능 없는 HP·MP·가방을 꾸며 넣지 않습니다.
- 원형 미니맵은 실제 마을 데이터와 내 위치를 사용합니다. ‘첫걸음’은 마을 어른과 실제 대화를 시작하면 1/1이 되고 저장됩니다.
- 달빛 원경·꽃잎·안개는 별도 시각 레이어입니다. 카메라가 위쪽 경계로 이동하면 원경을 줄여 실제 바닥 이동 영역을 확인할 수 있습니다.
- 이동 입력은 매 물리 틱마다 읽습니다. HD 텍스처 첫 업로드로 렌더가 지연된 프레임에서도 입력을 반영합니다.
- 기존 저장 스키마 1에 선택적인 `talked_to_elder` 값만 더합니다. 해당 값이 없는 V0.1 파일도 불러올 수 있습니다.
- 디버그 APK의 로컬 입력 로그는 유지하지만 화면 진단 표식은 기본으로 숨깁니다. 개발 환경에서 `WOO_TOUCH_OVERLAY=1`로 표시할 수 있습니다.

## 변경 파일

`assets/woo/hd/` 원본 아트 5개, `assets/fonts/WooTitle.otf` 제목용 Noto Serif 부분 폰트, `scripts/woo/art_frames.gd` 아틀라스 메타데이터, `actor.gd`, `village.gd`, `village_prop.gd`, `ornament.gd`, `scenery.gd`, `petals.gd`, `minimap.gd`, `scripts/main.gd`, 조이스틱과 터치 진단, 저장 검증 및 테스트를 수정했습니다. Noto 라이선스는 기존 폰트 고지에 포함합니다.

## 빌드·검증

versionName 0.1.1 / versionCode 5, 패키지 `com.suspiciousfactory.game`, 기존 인증서, 최소 Android 10, ARM64와 가로 모드를 유지합니다. 외부 서버나 계정은 추가하지 않습니다.

게임 검사 53개, 터치 검사 115개, 저장 복구 11개, 별도 프로세스 write/read/exit, APK 검사 21개가 통과했습니다. 실제 APK의 리소스로 Linux OpenGL에서 같은 터치 검사를 반복하고 화면을 캡처합니다. 이는 Android OS 실기기 실행을 대신하지 않습니다.

**V0.1.1을 실제 갤럭시나 Android 에뮬레이터에서 실행하지 않았습니다.** 실제 FPS·발열·제조사 화면 대응은 휴대폰 확인이 필요합니다.

기존 APK를 보존하고 `jeon-woochi-0.1.1.apk`로 배포합니다. 공개 파일 재다운로드와 Actions Artifacts 전달 상태는 버전별 검증 JSON을 기준으로 합니다. 게임 빌드는 Cloud에서 수행하며 Actions의 파일 전달 성공을 원격 게임 재컴파일 성공으로 보고하지 않습니다.
