# 도사 멀티플레이 통합 2.0.2

기존 저장소/Godot4.6.3/GDScript/Android10+/ARM64/가로 화면/패키지/서명을 유지합니다. 작업 전 상태는 `backup/dosa-2.0.1-multiplayer`에 보존했습니다. 기존 모험·꾸미기·아이템·성장·저장은 초기화하지 않습니다. 후속 APK는2.0.2/코드13, 네트워크 프로토콜은3입니다.

## 휴대폰 플레이 순서

1. 기존 앱 위에 APK를 업데이트 설치합니다. 타이틀의 주 버튼은 **봉인의 밤 · 온라인**입니다. 기존 싱글플레이는 **그림 속 모험**, **이어하기**로 남아 있습니다.
2. 서버 주소를 입력하고 연결합니다. 공개 서버가 없다면 [무료 Render 안내](V2.0-SERVER.md)와 아래의 신규 키 설정을 따릅니다. 기존 서버도 최신 소스로 수동 배포해야 합니다. 구버전 서버는 버전 불일치를 안내합니다.
3. **그림 수련 · 도술 발견**에 입장합니다. 기존 여우의 숲에서 도술 문양 가까이 이동 → 문양 살펴보기 → 표시한3문양을 순서대로 터치하여 실제로 배웁니다. 항아리 문양과 그 옆 축지법 문양을 먼저 배울 수 있습니다. 습득 없이도 임무·회의·구출은 가능하며 도술이 없는 칸은 비어 있습니다.
4. 수련에서 돌아와 방 만들기/코드 입장/빠른 대전을 사용합니다. 6~8명이 모두 준비하고 방장이 시작합니다. 실제 요괴는 항상2명입니다.
5. 서버가 맵과 역할을 배정하고 **준비30초 동안 최종 도술2칸을 표시**합니다. 무료는 이 시점에 보유한 역할별 후보에서 딱 한 번 추첨합니다. 대전 중 다시 뽑을 수 없습니다.
6. 도사는 봉인 미션·구출·회의·봉인을 진행합니다. 둔갑술을 실제 장착했다면 사물/동물 가까이에서 **형상 추출** → 도술 버튼으로 변신합니다. 메뉴의 **기억한 형상 선택**으로 이번 맵에서 추출한 형상을 고릅니다. 다시 도술 버튼을 눌러 인간으로 돌아옵니다.
7. 요괴는 사물 추출·사물 둔갑을 사용할 수 없습니다. 공통 도술 후보에서도 제외합니다. 역할 고유 메뉴의 **타인 둔갑**은 다른 플레이어의 표시 캐릭터·의상·헤어·모자·장신구·색상·닉네임을 복제하지만 실제ID·역할·행동·투표 대상은 바꾸지 않습니다.

## 맵과 환경

실제로 존재하는 **달빛 계월촌**과 **안개 속 여우의 숲** 두 맵만 등록했습니다. 서버가 매 판 등록된 목록에서 무작위로 고르고 모든 참가자에게 같은ID를 보냅니다. 두 방의 맵·충돌 캐시는 독립적입니다. 숲은 기존 모험의 지형/연못/돌다리/사당을 재사용한 멀티 배치이며 모험 몬스터를 생성하지 않습니다. 마을은 기존 한옥·장터·골목을 사용합니다. 새로 그린 미구현 맵을 목록에 넣지 않았습니다.

`arena.gd`의 공통 레지스트리에 맵ID/이름/크기/시작8지점/미션 지점/봉인진/감옥/렌더링 스크립트/충돌 레이아웃을 정의합니다. 환경 에셋은 ID·종류·리소스·크기·충돌 반경·상호작용/변신/추출/추적 속성과 도술 반응을 가집니다. 새 맵은 동일 레이아웃 인터페이스와 데이터 등록으로 확장합니다. 실제3D 엔진으로 전환하지 않았습니다.

현재 지원 형상은 **항아리·나무 상자·바구니·등불·짚단·문짝·허수아비·고양이·강아지·닭**입니다. 월드 대상과 변신한 플레이어가 같은 렌더러/리소스를 사용하며 동물은4프레임 보행과 별도 이동 규칙을 사용합니다. 변신 중 이름표·식별 고리·기존 인체 그림자를 숨겨 외형 차이를 줄였습니다. 거대한 건물이나 등록되지 않은 대상은 추출하지 못합니다. 충돌은 외형 크기로 늘리거나 줄이지 않고 서버가 동일한 안전 반경으로 검사합니다. 숲의 기존 추가 대나무 위치도 렌더링과 충돌 데이터에 함께 반영했습니다.

미니맵은 현재 맵·미션·본인 위치만 표시합니다. 다른 플레이어의 비공개 위치는 표시하지 않습니다. 서버 시야 밖 플레이어도 전송하지 않습니다. 위치 보간, 서버 이동 검증, 축지 이동의 경로 충돌, 기존 추적 발자국·연막·조명 방해를 유지합니다.

## 도술 획득·장착과 보안

기존 오프라인 저장을 수정해 보유 목록을 업로드하는 방식으로 멀티 도술을 해금할 수 없습니다. 그림 수련은 서버가 실제 위치·접근 거리·문양 순서·논스·입력 간격을 검증하고 익명 플레이어의 보유 기록에 저장합니다. 8개 문양을 지원하며 천면 문양은 둔갑술 습득을 선행 조건으로 둡니다. 큰 새 어드벤처를 만들지 않고 기존 숲의 짧은 발견 수련으로 구현했습니다. 기존 오프라인 모험과 도술 기록은 보존하지만, 조작 여부를 확인할 수 없는 옛 클라이언트 기록을 새 서버 권한으로 자동 인증하지는 않습니다.

무료 계정의 대기실 칸은 추첨 예정 상태이며, 역할이 정해진 준비 단계에 최종 추첨합니다. 요괴에게는 사물 둔갑을 후보에서 제거하므로 사용할 수 없는 도술이 칸을 차지하지 않습니다. 보유가2개 미만이면 기본 임시 정책은 빈 칸 허용입니다. `missing_spells=require_two` 설정으로2개를 요구할 수도 있지만 기본은 신규 진입을 막지 않습니다. 같은 도술을 중복 장착하지 않습니다.

일반 유료 규칙은 보유 중 직접2개 선택, VIP 규칙은 직접2개+별도 예비1개입니다. 서버는 실제 보유·서버 등급·역할별 후보·중복·칸 수·준비 시점을 검사합니다. VIP도 세 번째 도술을 동시에 사용할 수 없으며 대전 중 예비 교체는 명시적으로 비활성화했습니다. **결제 검증은 미구현이므로 실제 운영 계정은 전부 무료**입니다. 유료/VIP는 순수 로직 테스트 및 서버의 명시적 `SEAL_TEST_ENTITLEMENTS=1` 테스트 설정과 서버 기록으로만 검증합니다. 클라이언트가 tier/VIP/purchased를 보내도 혜택을 지급하지 않습니다.

천면술의 현재 공통 효과는 이름표/색상 기척을 숨기는 은형이며, 다른 플레이어 복제는 요괴 고유 능력으로 분리했습니다. 요괴 고유 능력은 공통 장착 두 칸을 소비하지 않습니다.

## 색상·식별·회의

서버가8가지 서로 다른 기본 색상을 배정합니다. 일반 외형을 바꾸어도 실제 기본 색상은 유지하며 역할에 따른 특별 색상은 없습니다. 캐릭터 옆 이름표와 발밑 고리, 대기실·회의에 같은 기본 색상을 사용합니다. 요괴 둔갑은 표시 색상만 복제하고 회의 명단은 원래 참가자ID와 기본 색상을 씁니다. 투표는 색상 문자열이나 현재 외형으로 대상을 찾지 않고 실제ID로 처리합니다. 역할 배정과 시작 위치 배치도 별도로 무작위화하여 특정 시작 위치가 요괴를 뜻하지 않도록 했습니다.

기존 임무4종·포획·감옥·구출·투표·기권·동점·최종 봉인·승패·재대전·방장 이전·40초 재접속을 유지합니다. 오봉인은 기존 활동 제한을 유지하되 수치는 임시 서버 설정입니다.

## 임시 밸런스 설정

`settings.gd`와 `catalog.gd`에 수치를 분리했습니다. 기본 테스트값은 준비30초/경기480초/토론30초/투표20초, 회의6회/자원1/재회의45초, 오봉인 제한35초, 추출 거리76/채널1초/보관6형상, 둔갑9초/재사용12초, 사물 이동46/동물78입니다. 이 값들은 최종 기획 확정이 아니며 서버 스냅샷에도 임시 설정임을 표시합니다. 예비 교체 조건은 미구현·비활성입니다.

## 저장 복원과 무료 서버

기존 `seal_identity.json`에 서버별 발견 기록과 서명 체크포인트를 추가합니다. 모험 저장·꾸미기 저장 파일은 초기화하지 않습니다. 서버는 보유 도술·승수·인증 해시를 서버 전용 파일에 보관합니다. HMAC 서명 체크포인트는 실제ID와 원래 인증 비밀값의 해시에 묶이고 클라이언트가 도술이나 승수를 바꿀 수 없습니다. 더 오래된 체크포인트가 최신 획득/승수를 줄이지도 않습니다. 체크포인트는 유료/VIP 권한을 포함하지 않습니다.

Render Blueprint의 **SEAL_PROGRESS_KEY**는 서버에서 자동 생성하고 유지합니다. 기존 서버를 수동 구성했다면 Render 환경변수에서 충분히 긴 비밀값을 생성해 보관하세요. 앱·GitHub·채팅에 넣지 마세요. 같은 키를 유지하면 무료 호스트의 파일이 사라져도 앱에 저장한 유효 서명 기록을 검증해 복원합니다. 키와 앱 데이터가 모두 사라지는 경우, 다른 기기로 자동 복구하는 계정 시스템은 없습니다. 기존 무서명 기록도 로컬에서 삭제하지 않지만 서버 인증 없이 경쟁 권한으로 복구할 수 없습니다.

무료 Render의 유휴 절전·콜드 스타트·월 사용량 한도는 여전히 적용됩니다. 공개 서버는 이번 환경에서 배포하지 않았습니다. 기존 안내대로 Free/카드 미등록/유료 전환 금지를 유지합니다. 서버 상태는20Hz 판정/10Hz 전송하며 WebSocket 바이너리 gzip 압축으로 전송량을 줄였습니다. 클라이언트는 압축 해제 크기를 제한합니다. 실제 무료 인스턴스에서의 지연·장시간 부하는 미검증입니다.

## 검증·미완료

순수 규칙 테스트로 맵 무작위 선택/서로 다른 방의 독립 충돌/8색 고유성/유무료VIP 장착/미획득 차단/요괴 후보 제외/형상 거리·장착 조건/복제 후 실제ID 유지/서명 위변조·복원을 검사합니다. 실제 WebSocket 클라이언트6개가 각각 수련을 완료하고 같은 방에 들어가 장착·추출·사물 둔갑·인간 복귀·요괴 복제를 수행하는 통합 테스트도 있습니다. 별도8인/6인 접속·재접속·방장 이전과 네이티브 터치 UI 회귀를 유지합니다. Linux 렌더러에서 수련과 멀티 맵을 실제로 캡처했습니다.

**이 자동화 클라이언트는 사람 또는 Android 기기라고 보고하지 않습니다.** 갤럭시6~8대의 인터넷 실기기 플레이·멀티터치·장시간 성능, 실제 Render 배포는 미검증입니다. 실제 구매·VIP 결제·예비 교체·3D 렌더러·건물 등 무제한 사물 형상은 미구현입니다. 최종 테스트 수·APK·Actions 증거는 배포 결과에 별도 기록합니다.

주요 변경: `scripts/seal/{arena,settings,loadout,study,study_ui,environment_asset,color_marker,minimap,progress_ticket,codec}.gd`, 기존 server/rules/client_ui/connection/catalog/world_fx, `scripts/main.gd`, actor/forest/forest_layout, 동물 아틀라스, 네트워크·도술·서명·기존 UI 회귀 테스트, 빌드 검증 도구, Render 환경 설정과 본 문서입니다.
