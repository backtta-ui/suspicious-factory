# 개인정보 처리방침 초안 — 0.1.0 오프라인 테스트에 한함

이 테스트 앱은 회원가입을 요구하지 않으며 인터넷 통신, 광고, 인앱결제, 분석 SDK, 원격 충돌 수집을 사용하지 않습니다. 닉네임, 모자·조끼 선택과 카메라 설정은 기기 안의 앱 전용 저장소에만 저장합니다. 제3자에게 전송하지 않습니다. Android 자동 백업을 비활성화했습니다. 앱 데이터 삭제 또는 앱 제거로 해당 설정을 삭제할 수 있습니다.

이 문서는 Google Play 정식 출시용 공개 정책이 아닙니다. 멀티플레이 서버, 익명 ID, 채팅·신고, 접속·보안 로그, 오류 수집이 추가될 때 수집 항목·목적·보관 기간·삭제 요청 방법·수탁사·운영자 연락처를 확정하고 실제 구현에 맞춰 갱신해야 합니다.
