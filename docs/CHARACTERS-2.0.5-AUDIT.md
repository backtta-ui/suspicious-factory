# 캐릭터 방향 에셋 조사 (수정 전)

- `hd/hero.png`: 전우치 전신 8방향/여러 걷기 자세가 실제로 있음. 그러나 현재 HeroRig는 항상 행4만 선택한 뒤 그림을 잘라 팔/다리를 회전함.
- `wardrobe/layers.png`: 네 캐릭터의 정면 머리, 정면 의상, 정면 헤어/모자/장신구만 존재. 연화/무영/홍련의 방향별 완성 전신·걷기는 없음.
- `wardrobe/head_parts.png`: 깨끗한 얼굴 및 앞/뒷머리는 있지만 모두 정면 구성용. 측면/후면 전신을 제공하지 않음.
- `v12/npc_walk.png`: 주민 NPC용. 도사 네 명의 외형/꾸미기 애니메이션을 대체할 수 없음.
- `v14/hero_actions.png`: 현재 주인공과 다른 비율/외형이 섞여 있고 꾸미기용 방향 부품이 없어 새 기본 도사로 취급하지 않음.
- `profile.gd`: 단일 appearance만 저장해 캐릭터마다 독립적으로 복원 불가. `screen.select`는 이전 요구에 따라 장비를 계속 유지했으나 이번 요구는 기본 차림/캐릭터별 저장 복원으로 변경됨.
- `visual.gd`: 의상은 항상 정면 그림이고 얼굴/헤어만 숨기거나 반전. 실제 방향별 몸통 리소스가 없으므로 좌표 보정으로 해결 불가능.

원본 파일/소유권은 보존하며 새 방향 리소스를 별도로 추가한다. 없는 방향을 정면 반전으로 대체하거나 구현 완료로 표시하지 않는다.
