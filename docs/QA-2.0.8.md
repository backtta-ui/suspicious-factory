# 도사 2.0.8 통합 QA 및 공통 UI 개선

이 문서는 **상용 품질 전체 완료 선언이 아니다.** 실제 실행 검사, 정적 조사, 화면 표본 관찰, 미구현, 실기기/공개 서버 제한을 구분한다. 기존 Godot4.6.3/GDScript·패키지·서명·저장 구조를 유지한다. 멀티플레이 맵과 승패/역할/도술 규칙은 변경하지 않았다.

기준: `06eca8b96f299cbc1922297365de48b584248421`(2.0.7). 원격 백업: `backup/dosa-2.0.7-before-integrated-qa`.

PASS=실제 해당 검사 통과, FIXED=원인 수정 후 해당 회귀 검사 통과, FAIL=검사 실패, MISSING=필요한 기능/에셋 미완성, BLOCKED=기기·공개 서버 등 환경 제한, DESIGN REVIEW=기획/미술 합격 기준 판단 필요. 자동 시나리오 수와 프레임/조합 내부 assertion 수를 합쳐 부풀리지 않는다. 최종 수치는 machine-readable QA ledger에 별도 기록한다.

## 공통 UI 구현과 한계

- `scripts/ui/design.gd`: FONT/남색·먹색·금색, panel padding, joystick 크기·안전영역, action 좌표, HP/정보 좌표, popup 시간, icon 장식, 긴 문장 줄바꿈.
- `popup_scroll.gd`: 일반 메뉴/온라인 팝업/수련 도술 목록의 터치 드래그와 버튼 클릭 분리.
- `vital_bar.gd`: 실제 값과 연결되는 공통 HP 표시. 수련 HP는 임시 값이며 실제 RPG HP/도력을 바꾸지 않는다.
- `nameplate.gd`: 수련 NPC/주민/몬스터의 공통 이름·HP 표현. 주민은 가까운 상호작용 대상 중심, 몬스터는 실제 체력 감소 표시.
- `loading.gd`: 수련장 준비 안내·독립 부적 움직임. 그림 전환은 기존 도술 연출을 보존하고 실제 그림 리소스를 연결했다.
- 기존 joystick/mobile_button/skill_badge를 재사용. 원형 action은 공통 눌림·비활성 표시를 사용한다. 일반 버튼 효과음은 기존 sound의 `button`을 유지한다.
- 공격/첫 도술/상호작용의 실제 좌표를 공유하고, 전투 없는 공간에는 공격을 추가하지 않는다. 온라인은 역할별 기존 버튼 구조를 보존하면서 같은 디자인/제스처를 사용한다.

**한계:** 가방·캐릭터 꾸미기·타이틀·그림 캐러셀은 기능상 필요한 독립 레이아웃을 유지한다. 모든 내부 색상/폰트/여백이 토큰 하나로 완전히 치환된 것은 아니다. 공통 ConfirmDialog/Toast의 전면 교체, 모든 경로의 비동기 리소스 로더, 모든 NPC 밀집 상황의 완전한 이름표 충돌 해소는 완료로 주장하지 않는다.

## 환경 제한 및 실제 기기 추가 검사

실제 Galaxy/Android 장치가 연결되지 않았다. 화면 잠금/OS 강제 종료/하드웨어 내비게이션/물리 안전영역/터치 드라이버/발열·지속60FPS/메모리 압박은 BLOCKED다. 로컬 WebSocket 자동 클라이언트와 휴대폰6~8대 인터넷 실전은 별개다. 공개 서버가 배포되지 않아 인터넷 실기기 검증도 BLOCKED다. Render 결제/유료 플랜을 추가하지 않았다.

데스크톱 렌더링이 가능한 화면은 PNG로 캡처하고 표본을 관찰한다. 완전한 Cartesian 애니메이션 미술 합격 판정은 하지 않는다. FPS 수치가 있더라도 Linux software renderer 관측치만 기록하며 Galaxy 수치로 환산하지 않는다.
