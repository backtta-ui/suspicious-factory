# 도술 모의전 V1.1 — 오프라인 봇 통합

기존 프로젝트의 공통 `SealRules`와 온라인 월드·HUD·임무 퍼즐을 재사용했다. 네트워크 연결 대신 인프로세스 권한 실행기가 입력 명령을 전달한다. 별도 미니게임 규칙이나 가짜 온라인 참가자가 아니다. **온라인 동기화 검증으로 주장하지 않는다.**

## 플레이 방법

1. 광장 남쪽 돌길의 ‘도술 모의전’ 표지에 접근해 입장한다.
2. 캐릭터·도술을 고른다. 이미 두 칸이 찼으면 기존 도술을 눌러 해제한 뒤 새 도술을 추가하고 선택 완료한다.
3. 준비 완료 → 모의전 시작. 카운트다운 뒤 실제 맵과 역할을 무작위 배정한다.
4. 기존 규칙의 최초 30초 준비 단계에서는 요괴 이동이 제한된다. 도사는 임무 위치를 탐색할 수 있다.
5. 도사는 임무/문양 퍼즐, 동료 구출, 봉인 회의를 진행한다. 구출은 역할 버튼을 누르고 유지하며 손을 떼면 취소된다.
6. 요괴는 메뉴에서 고유 능력을 선택한다. 타인 둔갑은 보이는 참가자를 선택해 복제한다. 둔갑 해제는 메뉴에서 제공한다.
7. 탈락하면 관전 대상을 바꿀 수 있고 봇은 계속 게임을 진행한다. 결과에서 재대결 또는 광장 복귀를 선택한다.

## 구현

- 광장 남쪽 돌길의 **도술 모의전** 입구. 입장 전 광장 노드와 플레이어·방향·카메라를 유지하고 잠시 숨긴다. 복귀 시 해당 노드를 그대로 활성화한다.
- 기본 1명+봇 5명, 7·8인 옵션. 참가자 외형·식별 색상·준비, 캐릭터 4종 선택, 캐릭터별 기존 차림 재사용.
- 기본 테스트 2칸, 개발 테스트 3칸. 모든 **멀티플레이 공통 도술 8종**을 임시 소유한 로컬 참가자만 생성한다. 실제 프로필·패스·도술 소유권에 기록하지 않는다. 요괴의 사물 둔갑은 역할 확정 시 제외·대체한다.
- 3초 카운트다운 중 시작/외형/장착 중복 변경을 막는다. 시작할 때 공통 RNG로 맵과 요괴 2명을 배정한다. 로비에서는 역할을 공개하지 않는다.
- 공통 로딩 화면에 실제 선정 맵을 표시한다. 경로 그래프 구축을 여러 프레임에 나눠 진행하고 맵·카메라가 생긴 뒤 입력을 허용한다.
- 실제 임무 4종: 사당 문양, 우물 문양, 혼불 운반, 부적 조각 수집. 온라인 미니게임과 같은 명령·nonce·입력 대기시간·충돌 검증을 사용한다.
- 포획 45초 / 기본 구출 4초 / 구출 후 보호 3초. 해봉술의 기존 구출 단축도 유지한다. 구출 버튼을 누르는 동안 진행하며 손을 떼면 권한 채널을 취소한다. 탈락하면 대상 선택 관전으로 전환하며 봇은 계속 진행한다.
- 결과에 팀 승패·개인 역할·참가자 역할·임무/포획/구출 통계를 표시한다. 통계는 공통 판정 로그에서 집계한다. 재대결은 새 대기실과 새 라운드 ID를 사용한다.

## 실제 맵과 승리 규칙

실제 등록된 완성 멀티맵은 **달빛 계월촌(village)**과 **안개 속 여우의 숲(forest)** 두 개다. `playable` 메타데이터·씬 존재·임무 지점을 확인한 맵만 모의전 목록에 넣는다. 아직 없는 **월하의 서원은 MISSING**이며 선택 목록에 표시하지 않았다. 향후 실제 완성 맵을 레지스트리에 등록하고 playable=true를 지정하면 목록에 포함된다.

기존 승리 규칙을 유지했다. 임무 완료는 봉인 회의 기회를 얻는 행동이며, 요괴 두 명을 투표로 봉인하면 도사팀이 승리한다. 도사 모두 최종 탈락하거나 기존 480초 제한까지 봉인을 막으면 요괴팀이 승리한다. 임무 4개 완료만으로 즉시 승리하도록 규칙을 바꾸지 않았다. 나머지 미확정 밸런스는 기존 설정값이다.

## 봇

0.35초 간격으로 행동을 결정하는 상태 머신이다. 참가자 자신의 필터링된 뷰와 직접 목격한 포획만 증거로 사용한다. 요괴는 동료 요괴 ID를 알지만 도사 봇에게 비공개 역할을 제공하지 않는다. 충돌 검사한 공유 AStar 경로를 목표 변경·정체 시 재계산한다.

도사는 임무·운반·조각 수집·구출·증거에 따른 도주·회의·투표를 수행한다. 요괴는 순찰·보이는 비동료 추격·외형 복제·포획·재배치를 수행한다. 분신과 가짜 혼불 조사, 연막/어둠의 시야 차단, 방어·이동·추적 등 장착 도술을 사용한다. 난이도는 초기 기본 한 종류다. 인간 수준의 추리 능력이나 완전한 밸런스를 보장하는 AI로 보고하지 않는다.

## 미완료·추가 검증

- 실제 갤럭시에서 설치→광장 입장→6·8인 완주→재대결, 화면 잠금·백그라운드 복귀, 60FPS/발열/메모리 측정은 BLOCKED다.
- 월하의 서원은 실제 프로젝트에 없는 맵이므로 이번에 구현 완료한 것으로 처리하지 않는다.
- 어드벤처 부적술을 멀티 규칙에 넣는 처리는 미완료다. HP 전투 규칙을 임의 추가하지 않았다.
- 봇은 기본 난이도 첫 구현이다. 장시간 경로·추리·도술 선택 밸런스의 실기기 플레이 검수가 필요하다.
- 기존 교체용 헤어·의상·모자 일부의 원본 호환 리소스 부족은 이전 그래픽 보고서와 동일하며 이번 범위에서 새로 제작하지 않았다.
- 온라인 역할 보호·실제 기기 동기화·지연·부정행위 방지 검증을 로컬 성공으로 대신하지 않는다.

내부 Android 빌드 번호는 기존 설치 업데이트를 위해 2.0.15 / versionCode 26으로 증가시켰다. ‘도술 모의전 V1.1’은 기능 업데이트 명칭이다. 기존 앱 패키지·프로젝트명·사용자 저장 경로·서명키를 유지한다.

## 이번 QA에서 추가 발견한 오류

- 긴 도술 설명이 선택 카드 폭을 넘어감: 짧은 선택 버튼과 줄바꿈 설명을 분리했다.
- 빈 슬롯이 선택 개수에 포함될 수 있음: 등록된 도술 ID만 편집·재구성에 사용한다.
- 재대결 라운드 ID가 다시 1이 되어 두 번째 결과창이 생략될 수 있음: 로컬 실행기에서 라운드 번호를 계승한다.
- 광장 복귀 뒤 배경음 음량이 낮게 유지될 수 있음: 공통 pause 해제를 호출해 이동과 음향을 함께 복원한다.
- 로딩 실패 복귀가 오류창을 너무 일찍 해제할 수 있음: 실패 상태에서는 오류 오버레이를 유지하고 안전한 광장으로 복구한다.
- 여러 명이 구조할 때 결과 통계가 다른 참가자에게 붙을 수 있음: 권한 판정 로그의 실제 구출자 ID를 집계한다.

최종 신규 자동 검사는 **81건/실패 0**이며, 별도 [경계 조건 검사](edge_cases.gd) **7건/실패 0**을 확인했다. [경계 결과](edge-results.json). 이는 자동·데스크톱 범위이며 물리적 Android 검사를 포함하지 않는다.
