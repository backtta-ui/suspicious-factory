# V1.4 전환 전 실제 상태 점검

기준 커밋: 1679618, 미커밋 V1.3 생존전 프로토타입을 별도 백업 커밋으로 보존한다.

- V1.3 작업에는 새로운 진입 씬과 10분 생존·봉인·구조·서클의 순수 규칙이 있다. 규칙/화면 준비 자동 검사 43건 통과 기록이 있으나 Android APK는 아직 빌드하지 않았다.
- 기존 SD 4종과 기존 배경을 재사용한 화면은 V1.4의 신규 외형/새 디자인 요구와 충돌한다.
- 로비의 큰 우측 메뉴 패널은 첨부 이미지의 중앙 대표 캐릭터·하단 매치 버튼 구성과 다르다.
- 기존 흐름은 양 진영 사전 선택 후 역할 배정이다. V1.4는 역할 무작위 배정 후 25초 동시 선택·자기 진영 제한·전원 확정/자동 확정이 필요하다.
- 기존 스킬 데이터는 하나의 active뿐이다. V1.4에 맞춰 기본 두 칸과 미확정 3/4번 칸을 분리해야 한다. 성장 보상이나 신규 3/4번 능력은 구현하지 않는다.
- 실제 캡처에서 경기 조작 버튼의 앵커/position 혼용으로 버튼이 화면 밖으로 벗어났다. 오프셋 기반 배치와 화면 크기별 입력 검사가 필요하다.
- 기존 RPG 진입점은 새 앱 실행에서 분리 중이다. 원본 소스와 기존 저장은 삭제하지 않고 보존한다. 새 저장 파일은 별도 경로를 사용한다.
- 재사용 기술: Android 패키지/서명/빌드, 네이티브 멀티터치 버튼과 조이스틱, 경로 탐색, 오디오, 파일 백업, 방향별 2D 스키닝 기술.
- 사용하지 않을 실행 요소: 광장·RPG·임무·회의·투표·인벤토리·성장, 기존 캐릭터 그림, 기존 화면 배치, 기존 광장/공장 경기 맵.
- 실제 갤럭시 시험은 수행되지 않았다. 온라인 생존전은 미구현이다.

참조: 이번 대화의 6분할 콘셉트 이미지를 직접 확인했다. 타이틀/로비/선택/방/VS/경기 화면의 배치·팔레트를 기준으로 사용하며, 이미지 전체를 UI로 붙이지 않는다.
