# 도사 2.0.9 — RPG UI/UX 개편 및 통합 회귀 검사

이번 변경은 기존 Godot 4.6.3 Android 프로젝트에 적용했다. 패키지, 지속 서명, 저장 스키마, 캐릭터·꾸미기 소유권, 맵, 카메라, 도술 판정, 멀티플레이 맵·역할·장착·승패 규칙은 유지한다. **전체 상용 품질 및 Galaxy 실기기 합격 선언이 아니다.** 아래 미완료와 BLOCKED를 함께 확인해야 한다.

기준 소스 `8ba7477f20538119b6800bbe304c3c9122cc9adb`, 원격 백업 `backup/dosa-2.0.8-before-rpg-ui`. UI 게임 소스 `15e6eb7ec0973954d7904570416d687e86845e6b`.

## 실제 적용

- **메인 메뉴:** 맵을 어둡게 남긴 중앙 패널, 실제 캐릭터·꾸미기·도감·가방·설정으로 연결되는 아이콘 카드 5개. 일지·지도·광장 복귀·메인 화면 복귀는 하단에 유지했다. 미구현 결제/권한을 추가하지 않았다.
- **도사의 옷장:** 왼쪽 실제 WooActor 전신 미리보기(기존 배율3 → 4.25), 방향8개·걷기·점프·공격 미리보기, 오른쪽6탭·스크롤 카드·보유/잠금/선택/리소스 미지원 상태, 하단 고정 저장/취소/기본 차림. 캐릭터별 저장과 기존 해금 조건을 재사용한다. 잠긴 캐릭터는 미리보기만 가능하고 저장은 기존 검증이 차단한다.
- **도술 도감:** 왼쪽14종 전체 목록·분류·터치 스크롤, 중앙 실제 catalog 설명/수련 기준 시간/현재 외형 배우 미리보기, 오른쪽 실제 RPG3슬롯 선택·장착·해제·수련 체험. 단순 동작 미리보기는 실제 도술 발동이라고 표시하지 않았다. 실제 효과는 동일 오프라인 수련장에 연결한다.
- **권한 구분:** 기존 모험 장착 가능 도술은 둔갑술/부적술이다. 온라인/수련 전용 기술을 모험에서 습득한 것으로 표시하거나 강제 장착하지 않는다. 온라인2슬롯/VIP 예비 규칙은 변경하지 않았다. 역할 도술은 별도로 표시한다. 수련은 실제 습득/장착/재화에 영향을 주지 않는다.
- **공통 디자인:** `design.gd`에 버튼 상태·높이54·보조 테두리·화면 여백·간격을 추가했다. 모든 일반 버튼은 같은 눌림/비활성 스타일과 기존 클릭 소리를 재사용한다. 강조 버튼에만 기존 장식을 남겼고 일반 버튼의 반복 금색 문양을 제거했다. 원형 HUD 아이콘은 유지한다.
- **공통 화면 틀:** 제목/닫기/본문/고정 하단, 안전 영역 여백, 패널·구름 실루엣·제목 구분선을 재사용한다. 기존 팝업 입력 차단·드래그 클릭 취소·짧은 등장/종료 페이드·로딩 입력 잠금은 보존한다.

참고 이미지는 대화 첨부를 확인해 3개 레이아웃 기준으로 사용했다. 지정된 원본 파일은 작업 경로에 없으므로 원본 파일과의 자동 픽셀 대조는 미검증이다. 참조 이미지의 레벨/HP/도력/도술 수치는 복사하지 않았다.

## 미완료 / BLOCKED

- 모든 화면을 새3열 화면으로 바꾸지는 않았다. 가방/그림 선택/수련/온라인 화면은 기존 목적별 레이아웃을 보존하고 공통 버튼 디자인을 적용했다. 일부 로컬 스타일 값, 온라인 대기실 모든 상태의 개별 재디자인, 모든 탭의 전환 애니메이션 추가는 미완료다.
- 모든 도술의 상용 수준 고유 다중 프레임 이펙트,5종 미지원 의상 방향별 아트, 추가 동물 동작, 임의 밀집 NPC 이름표 충돌 해결, 궁궐/해안 아트 고도화는 기존 미완료로 남는다. 소유권은 제거하지 않았다.
- Galaxy 실기기 터치/노치/뒤로가기 드라이버/화면 잠금/OS강제 종료/장시간 발열·메모리·60FPS는 **BLOCKED**. 빌드/주입 이벤트 검사로 대체 완료 처리하지 않는다.
- 공개 서버 및6~8대 실제 인터넷 경기는 **BLOCKED**. 로컬 소켓 검사를 실제 온라인 경기 완료로 보고하지 않는다. 기존 네트워크 구조/규칙은 변경하지 않았다.
