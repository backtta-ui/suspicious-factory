# 기존 2.5D 정리 결과

저장소: backtta-ui/suspicious-factory. 최신 방향 재설정 지시를 적용했습니다. 풀 3D 전환·신규 맵·신규 캐릭터 제작은 중단했습니다.

## 복구 지점

- `backup/v13-prototype-before-v14`: 96f6c63, 기존 2D 생존전 시제품.
- `backup/cancelled-3d-before-2d-cleanup`: 3e9c0ef, 취소된 3D 작업 전체.
- 사용자 저장 파일은 삭제/초기화하지 않습니다. 별도 생존전 설정 파일을 사용하며 이전 파일은 legacy-backup-v13에 사본을 남깁니다. 테스트는 격리된 사용자 디렉터리에서 실행했습니다.

## 정리한 기능

현재 실행 흐름과 APK에서 회의·투표·임무, RPG 어드벤처·성장·구매·재화·상점, 인벤토리·장비·꾸미기 화면과 진입점을 제외했습니다. 역사적 원본 소스를 저장소 전체에서 무차별 삭제한 것은 아닙니다. 기존 도술 시험의 공통 규칙 커널은 재사용하되 임무·회의·투표 명령을 차단했습니다. 취소한 3D 씬·모델·실행 코드는 현재 트리에서 제거하고 백업에 보존했습니다.

## 유지한 기능

기존 Node2D/Camera2D, 2.5D 맵·이동·충돌·터치 구조와 캐릭터 기본 갓·복장을 유지했습니다. 기존 14개 도술 시험을 로비에서 기록 변경 없이 사용할 수 있습니다. 새 캐릭터·맵·성장·자기장 페널티는 추가하지 않았습니다.

흐름: 타이틀 → 로비 → 오프라인 방 → 무작위 진영 → 25초 캐릭터 선택 → VS 실제 로딩 → 경기 → 결과/재대결. 준비·선택 확정·자동 선택·상대 선택 비공개를 검사했습니다. 기존 4개 외형과 임시 능력을 재사용하며 최종 한국 설화 캐릭터 명단/능력 확정으로 취급하지 않습니다.

6인(4:2), 8인(6:2), 600초 생존전, 봉인 성공12초/실패6초/유지45초, 구조4초/면역3초, 영구 탈락·관전·재대결을 유지했습니다. 자기장 단계는 0/180/360/480초이며 외부 감속·스태미나 감소는 제거했습니다. 외부 페널티와 최종 크기 밸런스는 미확정입니다.

## 실제 검증

`bash tools/checkpoint.sh` 종료0. 자동 검사 284개(정리39 + 생존전48 + 원본 외형128 + 도술61 + 무결성8), 두 봇 경기와 내보낸 팩 실행 검사를 통과했습니다. 내보낸 리소스 목록을 생성하고 팩을 원본 프로젝트 밖에서 직접 실행해 리소스 누락을 검사했습니다.

| 경기 | 결과 | 가상 경기시간 | 봉인/헛봉인/구조/스킬 |
|---|---|---:|---|
| 6인 | 요괴 승리 | 74.8초 | 5/6/1/9 |
| 8인 | 요괴 승리 | 122.75초 | 9/7/3/24 |

위 경기는 가속된 데스크톱 규칙 시뮬레이션입니다. 실기기 FPS나 10분 실시간 터치 시험이 아닙니다. 600초 도사 승리·서클 각 단계는 별도 규칙 검사로 확인했습니다. 화면비 1280×720/960×540/2400×1080 HUD 범위, 이동+달리기 동시 터치, 일시정지, 기존 저장 바이트 보존을 자동 검사했습니다.

캡처 01~12는 실제 Godot 데스크톱 실행 화면입니다. 캐릭터 선택과 경기 캡처를 직접 확인했습니다. 맵/미니맵과 일부 버튼은 시제품 표현이 남아 있으므로 상업용 최종 비주얼 완성으로 보고하지 않습니다.

## 실행 방법 / 미검증

APK를 설치하고 화면 터치 → 빠른 매칭(오프라인) 또는 게임 방 만들기 → 준비 완료 → 시작 → 진영에 맞는 캐릭터 확정 → 경기. 8인전은 방 만들기에서 선택합니다. 도술 시험은 로비의 기록 미반영 시험 버튼을 사용합니다.

실제 갤럭시 설치·멀티터치·홈 복귀·장시간 플레이·FPS/메모리는 BLOCKED(연결된 Android 기기 없음). 온라인 동기화는 검증하지 않았고 오프라인 참가자는 봇으로 표시합니다. 최종 능력/3·4슬롯 성장/자기장 밖 페널티는 구현하지 않았습니다. 사용자에게 앱 제거·데이터 초기화를 요구하지 않습니다.
