# 원본 캐릭터 적용 수정 — 2.0.12

## 실제 원인

1. 기존 런타임은 완성된 원본 대신 별도 제작된 몸체·헤어·모자를 합성했다. 작은 몸체를 다시 조각내면서 얼굴·표정·의상 무늬가 원본과 달라졌다. 이것이 실제 플레이 캐릭터가 달라 보이는 주원인이다.
2. 원본(1262×1246)은 균등 4×4 시트가 아니다. 기존 초상 아틀라스의 균등 분할도 무영의 머리 위 약 13px, 홍련의 두건 위 약 12px를 행 경계에서 잘랐다. 원본 완성형으로 교체할 때 이 분할 문제도 함께 수정했다.
3. 40px 몸체로 축소하고 48색으로 제한한 파이프라인이 원본의 세부를 손실시켰다.

## 수정

- 새 캐릭터를 생성하지 않았다. 기존 원본 파일은 그대로 유지했다.
- 행 경계 0 / 318 / 603 / 915 / 1246을 명시하고 각 캐릭터의 정면·좌측·후면·우측을 개별 투명 PNG 16장으로 무손실 분리했다.
- 원본 RGBA와 분리 PNG를 바이트 단위로 비교했다. 실루엣 주위 투명 여백도 검사했다.
- 기본 차림은 완성형 PNG 한 장으로 표시한다. 기존 캐릭터·합성 헤어·모자 레이어는 이 경로에서 숨긴다.
- 방향은 실제 원본 열에 연결한다. 좌우 반전하지 않는다. 발의 바닥 중심을 피벗으로 사용하고, 캐릭터별 동일한 단일 배율을 네 방향에 적용한다. 가로·세로 배율은 같다.
- 원본 PNG에는 색상 제한이나 비율 변경을 적용하지 않는다. Godot lossless import, mipmap 및 linear-with-mipmaps 필터로 축소 표시한다.
- 캐릭터 선택 카드와 HUD 초상도 같은 원본 정면을 사용한다.
- 기존 외형 ID·소유권·캐릭터별 저장·충돌·카메라는 변경하지 않았다.

## 검증과 남은 범위

- PASS: 16장 원본 픽셀 일치·투명 여백/잘림 검사.
- PASS: 실제 Actor 방향·원본 텍스처·균등 배율·발 피벗·구 이미지 숨김·점프/공격 중 디자인 유지 128개 검사.
- PASS: 외형 조합 504개 / 309,382개 구조·저장·전환 검사. 모든 조합의 미술 품질을 뜻하지 않는다.
- 기본 차림에 원본 완성 이미지를 적용했다. 헤어·의상 등을 변경한 조합은 기존 모듈식 경로를 보존하며, 원본 기반의 완전한 커스텀 레이어 분리는 후속 작업이다.
- 원본에는 방향마다 대기 그림 한 장만 있다. 별도 8방향·걷기·공격 프레임이 생겼다고 보고하지 않는다. 대각선은 가장 가까운 기존 전신 방향을 표시한다. 점프 위치·전투 판정·효과는 유지하지만 새 팔다리 애니메이션을 제작한 것은 아니다.
- BLOCKED: 갤럭시 실기기 표시·필터 품질·FPS 검증. 빌드와 실기기 검증은 별개다.
