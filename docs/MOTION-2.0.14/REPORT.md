# 2.0.14 — 기본색·해금·8방향 보행 개선

## 색상 및 저장

연화 기본색 ID가 원본과 다른 보라색이었고, 저장에 직접 선택 여부가 없었다. 기본색을 전우치 남색·연화 분홍색·무영 보라색·홍련 붉은색으로 정리했다. `color_override`는 색상 카드를 직접 선택했을 때만 설정한다. 캐릭터별 저장과 임시 미리보기는 분리된다.

저장 버전 3으로 이관한다. 이전 저장은 색상이 수동 선택인지 판별할 수 없으므로 기본색으로 표시하며, 기존 원본 값은 `legacy_appearance_v2`에 보존한다. 레벨·재화·아이템·진행도는 변경하지 않는다. 새로 직접 고른 색은 캐릭터별로 저장하고 재실행 시 복원한다.

## 꾸미기 해금 — 기능 범위 구분

헤어 6종, 의상 8종, 모자 6종+없음, 장신구 8종+없음, 색상 7종의 구매·레벨·승리·재화 조건을 없앴다. 기존 보유 목록을 삭제하지 않고 알려진 꾸미기 ID를 합친다. 캐릭터의 모험 해금 조건은 유지했다. 서버의 꾸미기 승리/결제 검증 조건도 제거했으며, 경기 시작 후 변경 금지·역할·포획·투표·도술 규칙은 변경하지 않았다.

**해금·선택·저장과 실제 교체 그림은 별개다. 교체용 원본 레이어가 없는 헤어·모자·의상 조합은 선택/저장은 가능하지만 여전히 원본 차림으로 표시하며 ‘리소스 준비 중’을 안내한다. 모든 교체 외형이 구현됐다고 보고하지 않는다.** 이 부분은 미완료다.

## 8방향 및 실제 움직임

- 기존 승인된 정면·후면·좌우 PNG 16장은 유지했다.
- 원본 디자인을 참고해 별도 대각선 전신 PNG 16장을 추가했다. 정면을 회전·늘이거나 좌우 반전해 대각선을 대체하지 않았다. 뒤쪽 대각선은 뒷모습이다.
- 방향별 원본 픽셀을 2D 스키닝 메시로 사용한다. 머리는 강체로 유지하고 소매/손에는 별도 가중치, 좌우 발에는 분리된 신발 레이어와 반대 위상을 적용한다. 전체 이미지 상하 이동만으로 만든 애니메이션이 아니다.
- 신발은 원본 픽셀에서 분리했다. 측면에서 가려진 발이 하나뿐인 경우 같은 원본 신발을 재사용한다. 손그림 걷기 원화를 수백 장 새로 그린 방식이 아니라, 원본 기반의 연속 2D 스키닝 대체 구조다.
- 걸음 위상은 실제 이동 거리에서 진행된다. 달리기는 기존 속도 142, 걷기는 88을 유지하면서 동작 폭과 재생 주기가 달라진다. 로컬 이동에 짧은 가속/감속을 추가했다. 서버 이동 규칙은 바꾸지 않았다.
- 조이스틱 작은 대각선 입력도 방향을 갱신하며, 정지 시 마지막 방향을 유지한다.
- `attachments.gd`의 캐릭터/방향별 허리·등 기준점에 스키닝 변형을 적용해 추가 장신구가 몸을 따라간다. 기본 머리·모자는 원본 스킨의 일부로 머리와 함께 움직인다. 독립 교체 레이어의 부착 검증은 리소스가 없어 미완료다.

## QA에서 추가로 발견해 수정

- 대각선 원화를 행 반올림으로 분류하면 다른 캐릭터를 연결하는 문제: 원화 상단 좌표로 행을 분리하고 원화 행 범위 검사를 추가했다.
- 보이지 않는 긴 버튼 텍스트 때문에 꾸미기 마지막 열이 화면 밖으로 밀림: 카드 텍스트 대신 고정 크기 라벨/메타데이터를 사용하고 실제 배치 크기를 검사했다.
- 이동 불가 상태에서 가속 캐시가 남아 미끄러질 수 있음: 비활성/변신/전투 정지/재시도에서 이동 캐시를 비운다.

## 미완료 및 미검증

- 모든 헤어·모자·의상 교체의 실제 원본 스타일 레이어 제작 및 조합 검수는 미완료다. 이번 해금이 그 리소스의 완성을 뜻하지 않는다.
- 스키닝은 동작을 구현한 첫 적용본이다. 세밀한 보행 자세·접지·옷자락의 상용 품질 미술 검수는 남아 있다.
- 실제 갤럭시의 터치·GPU 표시·FPS·메모리 및 인터넷 6–8대 검증은 수행하지 못했다. APK 빌드 성공과 구분한다.
