# 수상한 공장 — 갤럭시 테스트 APK

[APK 다운로드](https://raw.githubusercontent.com/backtta-ui/suspicious-factory/apk-downloads/suspicious-factory-0.1.0.apk)

Android 10 이상 ARM64 휴대폰용입니다. 다운로드 후 삼성 내 파일 → 다운로드에서 APK를 열어 설치하고, ‘공장 들어가기’를 누르세요.

0.1.0은 오프라인 1차 이동 테스트입니다. 메뉴, 캐릭터 꾸미기, 공장 맵, 터치 조이스틱, 이동·충돌·카메라 추적을 포함합니다. 멀티플레이는 아직 없습니다.

게임 자동 테스트 33개 및 APK 검사 18개를 통과했습니다. 실제 갤럭시 실행은 사용자의 확인이 필요합니다. 원본 소스와 자동 빌드 설정은 main 브랜치에 있습니다.

이 브랜치는 APK 파일 전달용입니다. SHA256SUMS.txt로 파일 무결성을 확인할 수 있습니다. 키·토큰은 포함하지 않습니다.
